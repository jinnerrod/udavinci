# Introducción

**WEKA** es una de las herramientas más utilizadas en el ámbito del Data Mining debido a su facilidad de uso y su amplia colección de algoritmos de aprendizaje automático. Diseñada para apoyar tareas de clasificación, regresión, agrupamiento y selección de atributos, facilita el análisis de datos tanto a personas que inician como a quienes ya tienen experiencia. Su **entorno visual** permite experimentar con diferentes técnicas sin necesidad de programar, lo que favorece el desarrollo de habilidades analíticas.

Además, WEKA es **software libre**, lo que posibilita su adaptación y extensión para diversos contextos educativos y profesionales. Gracias a sus **múltiples interfaces** —como Explorer, Experimenter y KnowledgeFlow— ofrece flexibilidad para distintos estilos de trabajo. En un mundo donde los datos crecen de manera acelerada, dominar WEKA se convierte en una ventaja clave.

# 1. ¿Qué es WEKA?

Empezaremos recordando que la **minería de datos** es el proceso de extracción de información y búsqueda de patrones que permanecen ocultos entre grandes cantidades de información.

Weka, **Waikato Environment for Knowledge Analysis**, es un conjunto de librerías JAVA para extraer conocimiento desde bases de datos. Es un software que ha sido desarrollado en la universidad de Waikato (Nueva Zelanda) bajo licencia GPL, es decir es software libre lo cual ha impulsado que sea una de los frameworks más utilizados en esta área. Weka contiene las herramientas necesarias para realizar tareas de minería de datos especialmente preparación de datos, clasificación, regresión, clustering, características de selección y visualización además de transformaciones sobre los datos. Una de sus **hipótesis** se basa en que los datos se encuentran todos en un único fichero plano tipo arff, que veremos más adelante. Una de las propiedades más interesantes de este software es su facilidad para modificar métodos, añadir extensiones etc. Weka funciona en cualquier plataforma en la que esté instalada una máquina virtual Java ya que está implementado en Java.

> **Importante**
>
> Existen otras herramientas similares como **Oracle Data Miner, Clementine**, otra desarrollada por IBM y otra por SAS pero el hecho de que Weka sea desarrollado bajo licencia GPL es decir software libre lo ha hecho una alternativa muy interesante y accesible.

En cuanto a las ventajas que presenta Weka frente a otras **herramientas** podemos destacar:

- Es software libre.
- Es muy portable ya que al estar desarrollado en Java se ejecuta en cualquier plataforma que ejecute la máquina virtual de Java.
- Su interfaz de usuario es muy intuitiva y no es necesario tener conocimientos de programación.
- Contiene una extensa colección de técnicas para el preprocesamiento de datos y el modelado.
- Weka soporta las tareas propias de la Minería de Datos, especialmente el preprocesamiento de datos, clustering, clasificación, regresión, visualización y selección.
- Weka carga datos desde ficheros planos tipo arff que tienen una estructura interna determinada. Si tomamos como ejemplo el fichero iris.arff que proporciona la misma instalación de Weka (por ejemplo en **C:\Program Files\Weka-3-8\data**) tendremos:
- **Cabecera**: @RELATION iris donde iris es el nombre de la relación. Es muy útil para grandes volúmenes de información ya que permite por ejemplo si contiene ventas por día, @RELATION dia_1, @RELATION dia_2, @RELATION dia_3 etc... y así podríamos hacer minería de datos solo de días concretos o de todos los días.

- **Atributos**: @ATTRIBUTE son los atributos del fichero y el tipo de datos y/o valores que pueda tomar. En el caso que estamos tratando
  - @ATTRIBUTE sepallength REAL
  - @ATTRIBUTE sepalwidth REAL
  - @ATTRIBUTE petallength REAL
  - @ATTRIBUTE petalwidth REAL
  - @ATTRIBUTE class {Iris-setosa,Iris-versicolor,Iris-virginica}

El último declarado es la variable muestra con las etiquetas, en este caso class con lo que tenemos 3 posibles **clasificaciones**.

---

- **Datos**: @DATA son propiamente los datos de la relación declarada al inicio del fichero.

```
@DATA
5.1,3.5,1.4,0.2,Iris-setosa
4.9, 3.0,1.4,0.2,Iris-setosa
```

En nuestro caso para la **primera fila** teniendo en cuenta los **atributos**:

- Sepallength = 5.1
- Sepalwidth = 3.5
- Petallength = 1.4
- Petalwidth = 0.2
- Class = Iris-setosa

- **Weka** también proporciona acceso a bases de datos vía SQL debido a la conexión JDBC (Java Database Connectivity) y puede procesar los datos devueltos por una consulta hecha a la base de datos.
- Ofrece también la opción de poder usar Weka por terceros a través de su API.

# 2. Técnicas de Data Mining en Weka

Weka es capaz de aplicar los siguientes **algoritmos de minería de datos**:

- De Clasificación: dada una serie de elementos etiquetados es capaz de predecir la etiqueta de nuevos elementos.
- De Regresión: predicen variables continuas basándose en otras características del conjunto de datos.
- De Selección de atributos: encuentra atributos nuevos.
- De Clusterización o Agrupamiento: identifica grupos con características similares.

La **evaluación** del **algoritmo de clasificación** puede realizarse de diferentes modos, según la selección en el cuadro "**Test options**"

1. **Use training set**: Esta opción evalúa el clasificador sobre el mismo conjunto sobre el que se construye el modelo predictivo por lo que proporciona una estimación demasiado optimista del comportamiento del clasificador, al evaluarlo sobre el mismo conjunto sobre el que se hizo el modelo.

2. **Supplied test set**: Evaluación sobre conjunto independiente. Esta opción permite cargar un conjunto nuevo de datos. Sobre cada dato se realizará una predicción de clase para contar los errores.

3. **Cross-validation**: Evaluación con validación cruzada. Esta opción es la más elaborada y costosa. Se realizan tantas evaluaciones como se indica en el parámetro Folds.

4. **Percentage split**: Esta opción divide los datos en dos grupos, de acuerdo con el porcentaje indicado (%). El valor indicado es el porcentaje de instancias para construir el modelo, que a continuación es evaluado sobre las que se han dejado aparte.

Además de estas opciones, el botón **More Options** abre un cuadro con otras opciones adicionales.

## 3.2. Experimenter

Al seleccionar esta opción, **Experimenter** permite configurar experimentos avanzados que integran varios conjuntos de datos dentro de una misma estructura de análisis. Esta herramienta facilita organizar la información, definir las fuentes de datos y establecer criterios de evaluación más amplios que los disponibles en los módulos básicos de Weka.

Además, Experimenter posibilita ejecutar diferentes **algoritmos de aprendizaje automático** de manera automatizada. Esta ejecución puede realizarse de forma secuencial o paralela, lo que agiliza el proceso cuando se trabaja con múltiples modelos o configuraciones. La herramienta incorpora **procedimientos estadísticos** que permiten comparar el rendimiento de los modelos de forma objetiva. Gracias a estos análisis, es posible identificar si las diferencias encontradas entre algoritmos son significativas, lo que ayuda a seleccionar la opción más adecuada según el tipo de datos y el objetivo del estudio.

## 3.3. KnowledgeFlow

**KnowledgeFlow** ofrece una ejecución de algoritmos sobre los datos similar a la que se realiza en Explorer, pero con un enfoque completamente visual. A través de un entorno basado en diagramas de flujo, permite construir procesos de análisis conectando componentes como fuentes de datos, filtros, clasificadores y evaluadores, todo ello mediante una interfaz intuitiva.

Este formato gráfico facilita comprender la **secuencia completa del procesamiento** y detectar de manera clara **cómo se transforman los datos** en cada paso. Además, permite modificar, añadir o eliminar elementos del flujo sin necesidad de cambiar configuraciones complejas, lo que hace más accesible el diseño de experimentos incluso para usuarios con menos experiencia.

Asimismo, KnowledgeFlow posibilita ejecutar los **flujos** creados en tiempo real, visualizar resultados parcial o totalmente y reutilizar los esquemas en distintos proyectos. Esto lo convierte en una herramienta flexible y potente para diseñar, probar y comparar procesos de aprendizaje automático con una mayor claridad y control sobre cada etapa.

>

La integración de todas estas **funcionalidades** en un solo entorno facilita la gestión de proyectos de aprendizaje automático, ya que permite combinar análisis exploratorios, experimentación y construcción de modelos sin interrupciones. Workbench proporciona así una experiencia más coherente y eficiente, especialmente útil para usuarios que necesitan supervisar y controlar múltiples aspectos del proceso de minería de datos de manera centralizada.

Esta selección "supervisada" aparece en contraposición a los filtros de la pestaña de "**Preprocess**" comentados anteriormente y que se realizan de forma independiente al proceso posterior, razón por la que se etiquetaron como "**no supervisados**".

La selección supervisada de atributos tiene dos **componentes**:

##### Método de Evaluación (Attribute Evaluator)

Es la función que determina la calidad del conjunto de atributos para discriminar la clase.

##### Método de Búsqueda (Search Method)

Es la forma de realizar la búsqueda de conjuntos.

Como la evaluación exhaustiva de todos los subconjuntos es un problema combinatorio inabordable en cuanto crece el número de atributos, aparecen estrategias que permiten realizar la búsqueda de forma eficiente.

---

> **Para saber más**
>
> De los métodos de evaluación, distinguimos dos tipos: los métodos que directamente utilizan un clasificador determinado para medir la calidad del subconjunto a través de la tasa de error del clasificador, "**wrapper**" y los que no. Los primeros son los **métodos "wrapper"**, porque "envuelven" al clasificador para explorar la mejor selección de atributos que optimiza sus prestaciones, son muy costosos. Entre los segundos destacamos el método "**CfsSubsetEval**", que calcula la correlación de la clase con cada atributo y elimina atributos que tienen una correlación muy alta como atributos redundantes.

De los **métodos de búsqueda**, distinguimos

- "**ForwardSelection**", destaca por su velocidad y es un método de búsqueda en escalada, es decir se elige primero el mejor atributo, después se añade el siguiente atributo que más aporta y así hasta llegar a la situación en la que añadir un nuevo atributo empeora la situación.
- "**BestSearch**", permite buscar interacciones entre atributos más complejas que el análisis incremental anterior. Este método va analizando lo que mejora y empeora un grupo de atributos al añadir elementos, con la posibilidad de hacer retrocesos para explorar con más detalle.
- "**ExhaustiveSearch**" simplemente enumera todas las posibilidades, las evalúa y selecciona la mejor.

# Recuerda

- **Weka**, Waikato Environment for Knowledge Analysis, es un conjunto de librerías JAVA para extraer conocimiento desde bases de datos. Es un **software** que ha sido desarrollado en la universidad de Waikato (Nueva Zelanda) bajo licencia GPL, es decir es software libre lo cual ha impulsado que sea una de los frameworks más utilizados en esta área.

- Weka contiene las **herramientas** necesarias para realizar tareas de minería de datos especialmente preparación de datos, clasificación, regresión, clustering, características de selección y visualización además de transformaciones sobre los datos. Una de sus **hipótesis** se basa en que los datos se encuentran todos en un único fichero plano tipo arff, que veremos más adelante.

- Weka es capaz de aplicar los siguientes **algoritmos** de minería de datos: de clasificación, de regresión, de selección de atributos y de clusterización o agrupamiento.

- Una vez que Weka esté en **ejecución** aparecerá una ventana denominada selector de interfaces, que nos permite seleccionar la interfaz con la que deseamos trabajar con Weka. Las posibles **interfaces** a seleccionar son Explorer, Experimenter, KnowledgeFlow, Workbench y Simple CLI que se explicarán de forma individual en las siguientes secciones.

# 1. Introducción aR

R, también conocido como "GNU S", es un entorno y un lenguaje para el cálculo estadístico y la generación de gráficos. R implementa un dialecto del lenguaje S, desarrollado en los Laboratorios Bell.

R se desarrolló inicialmente por Robert Gentleman y Ross Ihaka del Departamento de Estadística de la Universidad de Aukland, y actualmente su desarrollo es responsabilidad del R Development Core Team. Es un proyecto GNU y por tanto los usuarios son libres de modificarlo y extenderlo.

Entre las características de R podemos destacar:

- La capacidad para combinar, sin fisuras, análisis "preempaquetados" con análisis ad-hoc, específicos para una situación: capacidad de manipular y modificar datos y funciones.
- Gráficos de alta calidad para informes
- Comunidad muy dinámica, con gran crecimiento del número de paquetes (prácticamente uno anual) e integrada por estadísticos
- Extensiones específicas para áreas como bioinformática, geoestadística y modelos gráficos.
- Lenguaje orientado a objetos
- Se parece a Matlab y a Octave, y su sintaxis RECUERDA a C/C++.

Todo esto hace de R un lenguaje especialmente versátil para el manejo de elementos estadísticos, en concreto para operaciones con matrices y vectores, lo que facilita la manipulación de bases de datos. Por tanto, R, permite manipular (seleccionar, recodificar y recuperar) datos muy rápidamente. De hecho, existen algunos paquetes diseñado para ello como ***plyr***, lo que hacen que este lenguaje de programación sea mucho más hábil y eficiente en la preparación de los datos para su posterior análisis.

---

Debido a su nacimiento en el ámbito académico, fue diseñado específicamente para hacer análisis estadístico, por lo que es muy preciso y exacto para el análisis de datos. También desde sus inicios, R tiene implementados una gran cantidad de algoritmos para Machine Learning, como consecuencia de las diferentes líneas de investigación de grupos que dieron pie a su creación.

Como contra podemos destacar su curva de aprendizaje, pues suele ser más lenta y menos sencilla que la de Python, así como el escaso soporte para gráficos dinámicos o en 3D y la obligación de que todos los objetos se deben guardar en memoria física, con el problema que esto conlleva a la hora de intentar cargar objetos de gran tamaño.

Gran parte de las funciones de R están escritas en el mismo R, aunque para algoritmos computacionalmente exigentes es posible desarrollar bibliotecas en C, C++ o Fortran que se cargan dinámicamente. Los usuarios más avanzados también pueden manipular los objetos de R directamente desde código desarrollado en C.

## 1.1 Comandos en R

Aunque quizás no sea la forma más sencilla de usar, sobre todo si es un usuario inexperto, R permite ejecutarse de forma interactiva mediante la línea de comandos en consola. Una vez que abrimos el entorno, aparecerá lo siguiente:



*R Console*

Similar a como trabajamos con el Prompt de Anaconda para Python, podemos usar la consola de comandos de R. Tras el mensaje de apertura aparece el "prompt" de la consola de R que es el símbolo >.

Si se escribe e intenta ejecutar un comando que no se ha escrito por completo, el programa presenta un '+' que es el prompt de continuación. Para ejecutar un comando, simplemente se debe pulsar 'intro' tras escribirse en la consola.

Algunos de los comandos que pueden ser de gran utilidad en el uso de la consola de R, pueden ser los siguientes:

## 1.2 Objetos en R

R es un lenguaje orientado a objetos, esto significa que las variables, datos, funciones, resultados, etc., se guardan en la memoria activa en forma de objetos con un nombre específico. El usuario podrá modificar o manipular los objetos con operadores o con funciones.

Casi todo en R es un objeto, incluyendo funciones y estructuras de datos. De hecho, mientras que programas más clásicos muestran directamente los resultados de un análisis, R guarda estos resultados como un objeto, de tal manera que se puede hacer un análisis sin necesidad de mostrar su resultado inmediatamente.

Los objetos, por tanto, tienen nombre y contenido, pero también pueden tener atributos que especifican el tipo de datos representados por el objeto, de manera que la acción de una función sobre un objeto dependerá de los atributos de este último. Todo objeto tiene dos atributos de base, estos son tipo y longitud, donde tipo hace referencia a la clase básica de los elementos en el objeto (número, carácter, complejo, lógico, etc.), y la longitud es el número de elementos en el objeto. Las funciones mode() y length() nos devuelven los valores de los atributos tipo y longitud respectivamente para un objeto especificado como argumento.

Durante una sesión de trabajo en R, los objetos se almacenan por nombre, de manera que podemos obtener los nombres de los objetos almacenados en R con el comando **objects()**. La colección de objetos almacenados en cada momento se denomina espacio de trabajo (workspace). Así los objetos creados durante una sesión pueden almacenarse en un archivo en el directorio de trabajo con extensión .RData, de manera que en el siguiente inicio de sesión se recuperarán los objetos de este archivo así como el historial de órdenes. De hecho, antes de cerrar la sesión, R nos preguntará si queremos guardar el espacio de trabajo actual, por lo que es recomendable utilizar directorios de trabajo diferentes para cada problema y así evitar errores en el caso de que nombremos dos objetos de igual forma para espacios de trabajos diferentes.

# 2. ¿Qué necesitas?

Aunque originalmente R estaba pensado para entornos UNIX, en la actualidad puede obtenerse para diferentes versiones de Windows, Mac y Linux, lo que lo hace multiplataforma. Puede descargarse de varias formas: desde el código fuente escrito principalmente en C (con algunas rutinas en Fortran), para máquinas Unix/Linux, o como archivos binarios precompilados para Windows, Linux (Debian, Ubuntu, Redhat, Suse), y Mac.

Los archivos necesarios para la instalación de R, así como las instrucciones para llevarla a cabo se distribuyen desde https://ftp.cixug.es/CRAN/. A lo largo de este punto vamos a instalar y configurar R para un entorno Windows.

## 2.3. Entornos de desarrollo para R

Pese a que R trae integrado un entorno de desarrollo, con la consola y el editor de código, este puede parecer poco amigable, por lo que existe software como complemento a la programación en R con herramientas que simplifican el trabajo de programar nuestros scripts.

Dos de los entornos de desarrollo en R más extendidos y orientados a la analítica de datos, son RStudio y R Commander.

##### 2.3.1 R Commander

Es una interfaz gráfica de usuario (GUI) que cubre la mayor parte de los análisis estadísticos más habituales a través de una serie de menús desplegables, es decir, permite manejar R sin necesidad de conocer el lenguaje de comandos propio de este entorno. Esta característica, hace de R Commander un entorno bastante práctico si se está aprendiendo el uso de R.

No obstante, pese a que permite el uso de los menús para no utilizar el código de R, nos muestra una ventana de instrucciones en la que se va escribiendo el código de las operaciones realizadas, por lo que poco a poco, se pueden ir aprendiendo.

# 3. Tipos de datos

R soporta diferentes tipos de datos, desde los más básicos como son el tipo numérico, carácter, cadena de caracteres o valores booleanos, hasta otros más complejos como los tipos de datos compuestos: vectores, matrices, listas, etc.

Los datos pueden almacenarse en una variable que se identificará mediante un nombre, este nombre debe seguir una notación acorde a unas características:

- Debe comenzar por una letra
- El resto del nombre puede ser una sucesión de letras, números y los caracteres Punto (.) y guion bajo (_).

Se debe tener en cuenta que R, diferencia entre mayúsculas y minúsculas, y el nombre de una variable debe ser acorde a su contenido, es decir debe ser informativo utilizando por convenio el (.) para separar distintas palabras.

**Tipo de dato: Vector**

Como en cualquier otro lenguaje de programación en R, un vector puede contener una colección de datos del mismo tipo, ya sean numéricos, alfanuméricos o valores lógicos. Por lo tanto, no podremos incluir en un mismo vector datos de distinto tipo, como números y cadenas de caracteres, pues, aunque aparentemente R nos permita crear de esta forma el vector, internamente habrá convertido los números en cadenas de caracteres.

---

Los vectores en R permiten la indexación, es decir podemos acceder a un determinado elemento por medio de índices. También podremos concatenar, llevar a cabo aritmética vectorial o generar sucesiones.

Para crear un vector, se usa el operador de asignación <- y la función concatenación c().

##### Generando patrones

Podremos generar secuencias y almacenarlas dentro de un vector, con diferentes funciones en R.

- El operador ':' → Para generar un vector a partir de una secuencia usaremos dentro de la función de concatenación el operador ':', de manera que 1:3 genera el vector (1,2,3) y la secuencia 2:6 el vector (2,3,4,5,6). Este operador tiene máxima prioridad en una expresión, por lo que si ejecutamos c(2*1:15) obtendremos como resultado el vector (2,4,6,...,28,30), es decir que primero se genera el vector (1,2,3...,15) y después se multiplica por 2 cada uno de sus elementos.
- La función seq() → Nos permite generar sucesiones más complejas. Esta función dispone de 5 argumentos, (from, to, by, length, along) donde:
  - from: valor inicial
  - to: valor final
  - by: incremento de un dato a otro
  - length: longitud del vector
  - along: Su valor es vector y permite entre otras cosas la creación de un vector vacío si se usa como argumento único de la función.

La función rep() nos permite duplicar un objeto, por lo que sería otra forma de crear secuencias y almacenarlas en un vector.

##### Factores

Un factor se puede definir como un tipo especial de vector que se usa para especificar una clasificación discreta de los elementos de otro vector de igual longitud. Se pueden definir tanto factores nominales como ordinales.

Así, por ejemplo, si tenemos un vector que almacena las edades de un grupo de alumnos, podemos crear un factor con el fin de poder contabilizar cuántos alumnos tenemos de la misma edad:

edades.estudiantes <- c(25,26,18,30,24,18,33,41)

factor.edades <- factor(edades.estudiantes)

Podemos comprobar el contenido de factor.edades para ver qué ha ocurrido. Entre los recursos del módulo dispone de un archivo (factores.R) en el que aparecen más ejemplos de este tipo.

Los factores ordinales son aquellos en los que los niveles guardan un determinado orden. Para crear un factor ordenado o para transformar un factor en ordenado se usa la función **ordered()**.

---

Los factores los usaremos para datos cualitativos principalmente, pero es un error muy común utilizar variables aparentemente numéricas en análisis estadísticos, por ejemplo, nº telefónico o códigos postales. Por ello antes de utilizar un vector con caracteres cualitativos o cuantitativos dentro de un análisis, hace falta convertirlo en un factor.

Existen funciones que nos permiten convertir diferentes clases de objetos a modos diferentes. De este modo, podemos convertir factores a valores numéricos. En esta caso, R realiza la conversión haciendo uso de expresiones **as.numeric()** y **as.character()**. Para mantener los valores literales del factor, primero se convierte en carácter y después en numérico, lo que será de utilidad si en una variable se almacena valores numéricos y no-numéricos.

##### Tipo de dato: Matriz

Una matriz no es más que un vector con un atributo adicional, **dim**, que es a su vez un vector numérico de longitud 2, y define el número de filas y columnas de la matriz.

Para definir una matriz se usa la función **matrix(data = NA, nrow=1, ncol=1, byrow=False, dimnames=list())**, que tiene como argumentos, los elementos por columnas y la dimensión de la matriz. Por defecto, la función matrix considera una matriz con una sola fila y una sola columna con valor NA (Not Available). El argumento byrow indica si la matriz se irá completando por columnas (byrow=FALSE) o por filas (byrow=TRUE). El argumento dimnames es una lista de longitud 2 con los nombres de las filas y las columnas.

Algunas funciones útiles para el manejo de matrices son:

| **Función** | **Descripción** |
| :--- | :--- |
| dim(M1) | Devuelve las dimensiones de M1 |
| nrow(M1) | Devuelve el número de filas de M1 |
| ncol(M1) | Devuelve el número de columnas de M1 |
| rownames(M1) <- c("fila1", "fila2", ...) | Permite la asignación de nombres a las filas de M1 |
| colnames(M1) <- c("col1", "col2", ...) | Permite la asignación de nombres a las columnas de M1 |
| crossprod(M1,M2) | Devuelve el producto matricial cruzado de M1 y M2, es decir la transpuesta de M1 multiplicada por M2. Si no se especifica M2, se toma de nuevo M1 por lo que conseguimos XtX |
| outer(A1,A2) | Realiza el producto exterior de dos matrices (o vectores) sobre una función dada. También puede usarse el operador **%o%** en cuyo caso la función utilizada es el producto |
| t(M1) | Realiza la transpuesta de la matriz M1 |
| diag(M1) | Se puede usar para extraer o modificar la diagonal de una matriz o para construir una matriz diagonal |
| rbind(M1,M2) | Une dos matrices (M1 y M2) por filas |
| cbind(M1,M2) | Une dos matrices (M1 y M2) por columnas |
| solve(M1) | Invierte la matriz M1 (si se le da como argumento) y resuelve sistemas lineales de ecuaciones (cuando se le dan dos argumentos), para lo que el primer argumento debe ser una matriz cuadrada no singular y el segundo argumento es un vector o matriz de coeficientes. |
| eigen(M1) | Calcula los autovalores y autovectores de una matriz cuadrada, el resultado es una lista de dos componentes llamados **values** y **vectors** |
| det(M1) | Calcula el determinante de la matriz cuadrada M1 |
| length(M1) | Devuelve el número total de elementos de la matriz M1 |
| is.matrix | Devuelve True si el objeto es una matriz y False en caso contrario |

---

Para acceder a los elementos de una matriz se pueden usar índices para indicar el número de fila y columna del elemento, por ejemplo:

- M[1,2] → Devuelve el elemento en la posición fila = 1 y columna = 2
- M["fila1", "col2"] → Devuelve el mismo elemento del ejemplo anterior si se han dado nombre específicos a las filas y columnas de la matriz.
- M[1:2,2:3] → Devuelve otra matriz con los elementos de la fila 1 y 2 y columna 2 y 3 de M.
- Para extraer filas y columnas enteras como vectores de matrices utilizamos sólo el primer o segundo índice respectivamente → M[1,], M[,"col3"], M[,c(1,2)]

En cuanto a las operaciones con matrices, se debe tener especial cuidado en el producto, ya que **matriz*matriz** devuelve la multiplicación elemento a elementos, mientras que **matriz%*%matriz** es el producto matricial.

##### Tipo de dato: Array

Los arrays son variables multiindexadas, es decir es una colección de datos indexados por varios índices. La diferencia entre un array, con una matriz o un vector es el número de dimensiones:

- Vector: una dimensión
- Matriz: dos dimensiones
- Array: Tres o más dimensiones

La definición general de un array es de la forma:

**array(datos, dimensiones)**

y su manejo es similar al que se hace de matrices.

##### Tipo de dato: list

Podemos pensar en una lista como un vector que contiene varios objetos, pero en este caso, cada objeto puede ser de un tipo/clase diferente. Además, los componentes de una lista no tienen por qué tener la misma cantidad de elementos. Por lo tanto, una lista es una colección ordenada de objetos.

La definición general de una lista es de la forma:

**list(datos, num_elementos)**

Para acceder a los elementos de una lista, se puede hacer uso de los índices (como en los vectores y matrices) por posición o nombre del elemento (para este caso podemos usar los corchetes para indicar la posición o el símbolo $ seguido del nombre del elemento al que queremos acceder), o bien con las funciones **first(L1), second(L1)...tenth(L1)**.

---

La asignación de nombres a los elementos de una lista se puede hacer directamente cuando se crea la lista, por ejemplo:

Lista <- list(Matriz=x, Leyenda=y, Vector=z)

O bien mediante el uso de la función **names(L1)**:

names(Lista) <- c("Matriz", "Leyenda", "Vector")

##### Tipo de dato: data frame

La idea de data frame (marco de datos) está basada en un tipo especial de lista, en la que todos los objetos tienen la misma cantidad de elementos, pero mantienen la libertad de ser de tipo distinto. Por lo tanto, lo podemos asemejar a una tabla de datos, en donde las filas representan unidades de muestra y las columnas representan variables, por ello es el tipo de dato más usado para los datos experimentales.

La forma de definir un data frame es mediante el constructor de la clase **data.frame(elementos)**, si en alguna variable falta algún valor, se completará con NA (Not Available) para que todos los componentes tengan la misma longitud.

---

Al igual que las matrices tenemos los atributos **dim**, **nrow**, **ncol** y **dimnames**. Así mismo la función data.frame() puede usarse para transformar una matriz en un data frame. Si la matriz no tiene definidos nombres de filas y columnas, entonces data.frame() le asignará "1","2","3"... a las filas y "X1", "X2", "X3",... a las columnas.

Algunas funciones útiles para el manejo de data.frame son:

| **Función** | **Descripción** |
| :--- | :--- |
| head(d1) | Devuelve los primeros elementos |
| str(d1) y summary(d1) | Permiten ver el data.frame de forma resumida |
| as.data.frame(m) | Permite transformar el objeto pasado como argumento en un data.frame |
| cbind() y rbind() | Permiten añadir nuevos elementos por columnas o filas. |

---

Pese a que los data frame admiten cualquier tipo de elemento, se deben tener en cuenta ciertas restricciones definidas como:

- Los componentes deben ser vectores (numéricos, cadenas de caracteres o lógicos), factores, matrices numéricas, listas u otras hojas de datos.
- Las matrices, listas y hojas de datos contribuyen a la nueva hoja de datos con tantas variables como columnas, elementos o variables posean, respectivamente.
- Los vectores numéricos y los factores se incluyen sin modificar, los vectores no numéricos se fuerzan a factores cuyos niveles son los únicos valores que aparecen en el vector.
- Los vectores que constituyen la hoja de datos deben tener todos la misma longitud, y las matrices deben tener el mismo tamaño de filas.

## 3.1 Lectura e importación de datos

Habitualmente la inserción de datos en R, no se hace de forma manual, ya que por lo general la idea es trabajar con grandes volúmenes de datos. R permite la lectura de datos desde una gran variedad de archivos (.xls, .xlsx, .sav, .txt etc.), además de permitir la entrada manual de datos.

En la lectura de datos se debe tener en cuenta que R utiliza el directorio de trabajo para leer y escribir archivos, así que dos comandos necesarios para trabajar serán **getwd()**, que devuelve el directorio actual y **setwd()** para cambiar el directorio.

##### Función read.table()

Aunque existen diferentes funciones en R que nos permiten importar y exportar los datos, lo más usual es preparar los archivos de datos para importarlos como objetos data.frame mediante la función **read.table()**. Con esta función y sus argumentos podemos leer los ficheros e indicar cómo están construidos. Los argumentos que constituyen la función read.table() son:

---

| **Argumento** | **Descripción** |
| :--- | :--- |
| file | Es el nombre del archivo o la conexión, lo escribiremos entre "" o con una variable de tipo carácter, y posiblemente con su dirección si se encuentra en un directorio diferente al de trabajo, o una dirección remota a un archivo tipo URL(http://..) |
| header | Es una variable lógica (TRUE o False) que indica si el archivo contiene el nombre de las variables en la primera fila o línea |
| sep | Variable tipo carácter que indica cómo están separados los datos (tab, comas, ..., etc.) |
| quote | Especifica los caracteres usados para citar las variables en modo carácter |
| dec | Carácter utilizado para representar el punto decimal |
| row.names | Un vector con los nombres de las líneas de tipo carácter o numérico (por defecto: 1, 2, 3...) |
| col.names | Un vector con los nombres de las variables (por defecto: v1, v2, v3, ...) |
| as.is | Controla la conversión de variables tipo carácter a factores (si es FALSE) o las mantiene como carácter (TRUE); as.is puede ser un vector lógico o numérico que especifique las variables que se deben mantener como caracteres. |
| na.strings | El valor con el que se codifican los datos ausentes (convertido a NA) |
| colClasses | Un vector de caracteres que proporciona clases para las columnas |
| nrows | El número máximo de líneas (filas) a leer |
| skip | Se utiliza en el caso de ser necesario saltarse algunas líneas a partir del inicio del fichero. |
| check.names | Si es TRUE, chequea que el nombre de las variables sea válido para R. |
| fill | Si es TRUE y todas las filas no tienen el mismo número de variables, agrega "blancos" |
| strip.white | (Condicional a sep), si es TRUE, borra espacios extra antes y después de variables tipo carácter. |
| blank.lines.skip | Si es TRUE ignora líneas en "blanco" |
| comment.char | Un carácter que define comentarios en el archivo de datos; líneas que comiencen con este carácter son ignoradas en la lectura (para desactivar este argumento se utiliza comment.char ="") |

---

No obstante y pese que a través de los argumentos de read.table se permite acceder a la lectura de cualquier tipo de archivo, existen variantes de esta función, en la que se han definido las opciones por defecto para cierto tipo de archivos, como son:

- **read.csv** (file, header = TRUE, sep = ",", quote = "\"", dec = ".", fill = TRUE, ...) → Lectura de archivos .csv
- Para importar datos cuyo formato sea .txt separados por tabulaciones se puede utilizar tanto la función **read.delim()** o **read.table()**, lo importante es utilizar el argumento sep que indica la forma en cómo se han separado las columnas en el archivo.
- **read.fwf()** → Permite leer un archivo con las fechas en formato de ancho fijo, es decir, cada columna de los datos tiene un número fijo de caracteres.

Además de las opciones anteriores, para leer datos desde otros formatos se debe hacer uso de la librería ***foreign***, que nos permite importar datos desde archivos en formato Excel, SPSS, etc, con las funciones read.spss(), read.dta(), read.xport(), read.xls() (del paquete gdata), etc.

---

##### Función scan()

La función scan() para la lectura de datos es más flexible que read.table, pues a diferencia de esta última permite especificar el modo de las variables. Además, nos permite tanto introducir los datos directamente desde la consola, el portapapeles o desde un fichero. Es necesario especificar el tipo de objeto que importamos: numéricos, carácter, complejo o lógico. Por defecto será numérico. Si los datos leídos no corresponden al tipo, ya sea por defecto o especificado a través de what, se generará un mensaje de error.

Para leer datos copiados de columnas desde HTML, Excel o Access, primero debemos comprobar qué tipo de datos vamos a copiar, así como especificar las características del mismo en caso necesario, por ejemplo, si queremos copiar los datos numéricos de una columna en Excel donde los decimales están separados por una coma (','), debemos antes de introducir los datos ejecutar:

**scan(dec = ",")**

ya que por defecto los decimales están separados por un punto. Tras ejecutar la opción anterior, podremos pulsar **Ctrl+V** para introducir los datos copiados.

---

Para introducir datos desde el teclado, tras ejecutar la función se podrán introducir los valores del vector separados por espacios, pulsaremos **Intro + Ctrl+D** cuando hayamos terminado de insertar datos. Como alternativa a scan() para introducir datos desde el teclado, aparece data.entry(), que abre una hoja que nos permite editar fácilmente el conjunto de datos a partir de un vector, matriz, etc., inicializado a 0.

Los argumentos que permiten modificar las opciones de lectura de datos con scan() son los siguientes:

| **Argumento** | **Descripción** |
| :--- | :--- |
| file | Es el nombre del archivo entre "" o con una variable de tipo carácter, y posiblemente con su dirección si se encuentra en un directorio diferente al de trabajo, o una dirección remota a un archivo tipo URL(http://..). Si los datos se introducen desde el teclado debe dejarse file en blanco. |
| what | Especifica el tipo(s) de los datos (numérico por defecto) |
| nmax | El número máximo de datos a ser leído, o si what es una lista, el número de líneas por leer (por defecto, scan lee los datos hasta que encuentra el final del fichero) |
| n | El número de datos por leer (por defecto no hay límite) |
| sep | El separador de campos usados en el archivo |
| quote | Los caracteres usados para citar las variables de tipo carácter |
| dec | El carácter usado para el punto decimal (punto '.') por defecto |
| skip | El número de líneas ignoradas antes de empezar a leer datos |
| nlines | El número de líneas a leer |
| na.string | El valor asignado a datos ausentes (convertido a NA) |
| flush | Si es TRUE, scan va a la siguiente línea una vez se han leído todas las columnas (el usuario puede agregar comentarios en el archivo de datos) |
| fill | Agrega espacios "blancos" si es TRUE y todas las líneas no tienen el mismo número de variables |
| strip.white | (Condicional a sep), si es TRUE, borra espacios extra antes y después de variables tipo carácter. |
| quiet | Si es FALSE, scan muestra una línea indicando los campos que han sido leídos. |
| blank.lines.skip | Si es TRUE ignora las líneas en blanco |
| multi.line | Si what es una lista, especifica si las variables de un mismo individuo están en una sola línea en el archivo (FALSE) |
| comment.char | Un carácter que define comentarios en el archivo de datos; líneas que comiencen con este carácter son ignoradas en la lectura (para desactivar este argumento se utiliza comment.char ="") |

## 3.2 Escritura o exportación de datos

Al igual que la función read.table() nos permite la lectura e importación de los datos, en R está implementada la función contraria, **write.table()**, que nos permite guardar el contenido de un objeto en un archivo. El objeto es típicamente un data.frame, pero puede ser cualquier otro tipo de objeto (vector, matriz, etc.).

Los argumentos que permiten configurar las diferentes opciones de la función **write.table()** son:

| **Argumento** | **Descripción** |
| :--- | :--- |
| x | Es el nombre del objeto a exportar |

## 3.3 Funciones

Una función es un grupo de instrucciones que, a partir de unos datos de entrada, realizan una serie de operaciones y retornan un resultado/producto. Una función puede tener varios argumentos, y se puede omitir especificar algunos de ellos, asumiendo que la función tomará por defecto unos valores preespecificados.

Al igual que en otros lenguajes de programación, debemos diferenciar en R entre **Procedimiento** y **Función**:

- Procedimiento: grupo de expresiones entre llaves que no producen ningún resultado
- Función: grupo de expresiones que sí produce un resultado.

Para crear una nueva función o procedimiento, agrupamos comandos o expresiones entre llaves. Además, las expresiones pueden ir separadas por ";" en la misma línea o por retorno de línea escribiéndolas cada una en una línea independiente.

La mejor forma de poder ejecutar expresiones de varias líneas es a través de ficheros script en R, esto nos va a permitir ejecutar varios comandos de una única vez.

---

La sintaxis general para crear una función será:

Nombre_función <- function (arg1, arg2, …) { expresión}

donde, expresión es el conjunto de líneas de código en las que se manipulan los argumentos para calcular la salida. El valor que se devuelve como resultado de evaluar la expresión con los argumentos proporcionados, es el valor que proporciona R en su salida y éste puede ser un simple número, un vector, una gráfica, una lista o un mensaje.

Si en la definición de la función damos un valor por defecto a los argumentos, éste será el que se tome en el caso de que no especifiquemos dicho argumento en la llamada a la función. Si al hacer la llamada a la función no especificamos el nombre del argumento, se asume que se están introduciendo en el orden definido en la función, para introducir los argumentos en un orden aleatorio debemos especificar el nombre de los mismos.

La función **args(nombre_funcion)** nos muestra los argumentos para la función pasada como argumento.

##### Estructuras de control en R

Las estructuras de control, nos permiten como su propio nombre indica, llevar un control en la ejecución del código.

Podemos agrupar las estructuras de control en dos conjuntos:

- Condicionales: Evalúan una condición y en función del resultado de la misma ejecuta una opción u otra. Así mismo, las estructuras condicionales pueden ser: simples, dobles o múltiples
- Iterativas: Una iteración es un ciclo de operaciones que se repiten en bucles y ciclos, por lo que deben utilizarse lo menos posible ya que ralentizan mucho los cálculos. Para evitar esto, existe en R unas funciones vectorizadas apply(), tapply(), sapply() que veremos más adelante.

##### Condicionales

Por defecto, las instrucciones de un programa se ejecutan secuencialmente, sin embargo, al describir la resolución de un problema, es normal que tengamos que tener en cuenta ciertas condiciones que influyen sobre la secuencia de pasos que hay que dar para resolver el problema. Es decir, según se cumplan o no determinadas condiciones, la secuencia de pasos involucrados en la realización de una tarea será diferente, por lo que las estructuras de control condicionales o selectivas nos permiten decidir qué ejecutar y qué no en un programa.

---

La estructura básica en R para una condición será:

**if (condición) { comando(s) }**
**else { comando(s) }**

que a su vez permite anidarse.

Así mismo, disponemos en R de una versión vectorizada de if, que es ifelse(), cuya estructura sería:

**ifelse(condición, comando 1, comando 2)**

de manera que una vez evaluada la condición se ejecuta el comando 1 si es TRUE o el comando 2 si FALSE.

Por otro lado, hemos comentado que if..else permite la concatenación, pero para evitar muchos if's cuando tenemos varias posibilidades de ejecución, disponemos de la función **switch()**, cuya estructura es la siguiente:

**switch (expresión, lista de opciones)**

en este caso se evalúa la expresión y acorde al resultado se devuelve la opción correspondiente de la lista de opciones. Si expresión es un dato numérico, se devuelve el ítem de la lista correspondiente a esa posición, de no existir se devuelve NULL.

---

##### Iterativas

Como hemos señalado anteriormente, las sentencias de control iterativas conllevan una ralentización de los cálculos, sobre todo si iteramos sobre un gran número de valores, no obstante, hay ocasiones en las que no hay más remedio que utilizar bucles y ciclos. Para ello R dispone de varias herramientas:

- **for:** Repite una acción un número determinado de veces, su estructura es la siguiente: **for (name in values) { expre }**, de manera que expre es evaluada asignando a name sucesivamente cada uno de los elementos de values.
- **while:** Comienza comprobando una condición y continúa siempre que se cumpla. Su estructura es la siguiente: **while (condición) {expre}**, de manera que expre es evaluada mientras la condición sea cierta.
- **repeat:** Repite un conjunto de instrucciones hasta que se satisfaga un criterio de parada. En R se usa la palabra **break** para indicar el momento de parar. Su estructura es la siguiente: **repeat {expre}**.

Otra instrucción que se usa con repeat, es **next**, si R se encuentra esta instrucción en un bucle iniciado con repeat, deja de ejecutar las instrucciones del bucle y recomienza el bucle desde el principio. Es importante resaltar que si olvidamos incluir la instrucción de parada entraríamos en bucle infinito.

---

##### Funciones apply, lapply y sapply

Dada la facilidad de trabajar con vectores en R, usualmente es posible reescribir bucles en términos de operaciones con vectores que resultan más breves y legibles, esto es lo que se conoce como vectorización. Para bucles grandes, este enfoque es más rápido y más fácil de leer, sin embargo, es necesario tener una idea aproximada del número de iteraciones que se requieren.

Para llevar a cabo lo explicado anteriormente, R implementa una serie de funciones que evitan el uso de bucles.

- **apply(x, MARGIN, FUN):** Actúa sobre las filas o las columnas de una matriz, donde X es la matriz, MARGIN indica si se van a usar las filas (1), las columnas (2) o ambas (c(1,2)), y FUN es la función (o un operador, en cuyo caso debe especificarse entre corchetes) a aplicar.
- **lapply(x, MARGIN, FUN):** Actúa sobre una lista y su sintaxis es similar a la de apply, exceptuando que la devolución de esta función es una lista.
- **sapply(x, MARGIN, FUN):** Es una variación más flexible de la función lapply(), que puede tomar un vector o una matriz como argumento principal, y devuelve los resultados en una manera más amigable, generalmente en una tabla.

Por tanto, apply, lapply y tapply son funciones muy útiles que contribuyen a hacer el código más legible, fácil de entender, y facilitan posteriores modificaciones y aplicaciones. Antes de aplicar un bucle debemos intentar sustituirlo por algún miembro de la familia apply, ya que se agilizarán los cálculos.

# 4. Estadística Descriptiva y Predictiva con R

La **estadística descriptiva o análisis exploratorio** de datos es la rama de las matemáticas que recolecta, presenta y caracteriza un conjunto de datos con el fin de describir apropiadamente las diversas características de ese conjunto. Ofrece modos de presentar y evaluar las características principales de los datos a través de tablas, gráficos y medidas resúmenes, es por tanto la ciencia que recolecta datos, los analiza, los ordena, los procesa (mediante herramientas matemáticas) y finalmente obtiene información para la toma de decisiones.

El tipo de gráfico a seleccionar depende del tipo de variable que nos interese representar. En estadística la clasificación de las variables es:

- **Cualitativas**: Variable que no se pueden medir numéricamente
- **Cuantitativas**: Variables medibles, es decir expresables como números y cumpliendo unas propiedades de medida. Por ejemplo: peso, talla, pulso, edad, precio, etc.
  - Discretas. Solo pueden tomar valores enteros
  - Continuas: Pueden tomar cualquier valor real dentro de un intervalo.

En estadística descriptiva, la forma más común de describir un conjunto de datos relacionados entre sí es dar un valor medio y una dispersión alrededor de dicho valor medio.

En R, es posible hacer cálculos de estadística descriptiva tanto para variables como para atributos, no obstante, para algunos cálculos será necesario instalar paquetes adicionales que contienen funciones específicas para realizar dichos cálculos estadísticos, dos ejemplos son las bibliotecas **modeest** y **fmsb** las cuales se utilizan para calcular la moda y los percentiles de una distribución respectivamente.

##### Funciones para cálculo de estadística descriptiva en R

Las funciones básicas para extraer información de parámetros como la media y la varianza las encontramos en el paquete base de R, mientras que otras como la mediana, la varianza, la desviación estándar y los cuantiles están dentro del paquete stats.

También existen numerosas funciones diseñadas para proporcionar una gama de estadística descriptiva a la vez, como es el caso de la función ***summary()***, que provee la media, la mediana, los cuantiles 25% y 75%, el mínimo y el máximo de un conjunto de datos. Otra función de este tipo es ***fivenum()***, que calcula el mínimo, el primer cuartil, la mediana, el tercer cuartil y el máximo de la variable.

Por otro lado, la función **table()** permite crear tablas de frecuencias para agrupar los datos, que pueden ser acumuladas si adicionalmente se emplea la orden ***cumsum***. Dada una tabla de frecuencia, es posible crear distintos tipos de diagramas, como el de barras o el de sectores como veremos más adelante. Así mismo, si queremos hacer el cálculo de frecuencias relativas simplemente se tendrá que ejecutar table() / sum(). Si ponemos varios vectores o factores dentro de table() se realizan tablas de referencias cruzadas.

En la tabla siguiente se muestra un resumen de las principales funciones en R para cálculos de estadística descriptiva.

| **Función** | **Descripción** |
| :--- | :--- |
| mean(x) | **Media**: Calcula la media aritmética de los valores de un vector numérico de datos |
| median(x) | **Mediana**: Calcula la mediana de los valores de un vector numérico x |
| var(x) | **Varianza**: Calcula la varianza de los valores x, que puede ser un vector o una matriz |
| cov(x,y) | **Covarianza**: Calcula la covarianza de x e y, que pueden ser dos vectores o dos matrices. Es necesario el paquete stats |
| cor(x,y) | **Correlación**: Calcula la correlación entre x e y, que pueden ser dos vectores o dos matrices. Es necesario el paquete stats |
| sd(x) | **Desviación estándar**: Calcula la desviación estándar de los valores x, que puede ser un vector o una matriz |
| fivenum(x) | Devuelve un vector con el mínimo, el máximo y los cuartiles del vector x |
| summary(x) | Devuelve la media, la mediana, los cuartiles, el mínimo y el máximo de un conjunto de datos. Además, define los nombres de los resultados |
| range(x) | **Rango**: Medida de dispersión que muestra los valores mínimo y máximo del conjunto de datos en R |
| quantile(x,n) | **Cuantiles**: Medida de dispersión que calcula el cuantil especificado mediante la probabilidad indicada con el argumento n que debe estar definida entre 0 y 1. |

##### Estadística predictiva en R

Las técnicas de estadística predictiva en R, nos permite desarrollar tareas básicas de Minería de Datos, como el pre-procesamiento de datos, análisis exploratorio de datos, y la construcción de modelos predictivos.

El análisis predictivo agrupa una variedad de técnicas estadísticas de modelización, aprendizaje automático y minería de datos que analiza los datos actuales e históricos reales para hacer predicciones acerca del futuro o acontecimientos no conocidos, permitiendo predecir tendencias y patrones de comportamiento.

La **regresión estadística** es una de las técnicas más empleadas cuando se busca determinar una variable respuesta en función de una o más variables explicativas. Por tanto mediante el análisis de regresión podemos explicar una determinada variable Y en función de una o varias variables X. En el primer caso estaremos en una regresión univariante, y en el segundo en una regresión multivariante.

Para determinar la relación lineal simple usaremos el comando **lm(Y~X)** que permite realizar la regresión y la función **predict.lm()** nos permite hacer predicciones sobre el modelo generado.

La regresión lineal múltiple funciona de forma similar al modelo de regresión lineal simple, con la diferencia de que lo que se estima es un plano de regresión. En este caso el comando que usaremos será **lm(Y~X1+X2+…+Xn)** donde cada X son las variables de las que depende Y.

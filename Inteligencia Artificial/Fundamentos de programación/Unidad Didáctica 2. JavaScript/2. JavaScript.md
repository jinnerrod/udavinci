# 1. JavaScript

Una de las características más destacadas de JavaScript es su capacidad para **admitir programación asincrónica**. Esto permite que múltiples operaciones se ejecuten de manera simultánea sin bloquear el flujo del código, lo que resulta esencial para crear aplicaciones web rápidas y responsivas que ofrezcan una experiencia fluida al usuario. La programación asincrónica facilita, por ejemplo, la carga de datos desde servidores sin interrumpir la interacción con la página, mejorando significativamente la usabilidad y la eficiencia de las aplicaciones modernas.

Además, JavaScript cuenta con un ecosistema amplio de **bibliotecas** y **frameworks** que amplían sus funcionalidades. Herramientas como React, Angular o Vue facilitan la creación de interfaces de usuario dinámicas y componentes reutilizables, mientras que Node.js permite ejecutar JavaScript en el servidor, convirtiéndolo en un lenguaje capaz de gestionar tanto el front-end como el back-end de una aplicación web.

> **Importante**
> 
> Se recomienda terminar una **declaración** con el símbolo de punto y coma (;), sin embargo, no es un requisito obligatorio, excepto cuando las declaraciones de varias sentencias se realicen en una sola línea, por ejemplo:
> 
> let a, b, c
> 
> a = 5
> 
> b = 10
> 
> c = a + b

Las **cuatro líneas** son declaraciones válidas y se ejecutan de manera secuencial:

- La primera sentencia declara la creación de tres variables de memoria llamadas a, b, c,
- La segunda sentencia indica la asignación del valor constante 5 a la variable a
- La tercera sentencia asigna el valor de 10 a la variable b
- La última sentencia ejecuta la suma algebraica de la variable a y la variable b y el resultado lo asigna a la variable c.

Cada una de esas **sentencias** pueden terminar con el carácter (;), por ejemplo:

---

> **Caso Práctico**
> 
> let a, b, c;
> 
> a = 5;
> 
> b = 10;
> 
> c = a + b;

El **resultado** obtenido de esta manera es el mismo. Así también podría escribirse todo el código en la misma línea, de la siguiente manera:

> **Caso Práctico**
> 
> let a, b, c; a = 5; b = 10; c = a + b;

Escribiendo el **código** en esta forma, el resultado y la ejecución será exactamente la misma. Ten en cuenta que los espacios en blanco en las sentencias son ignorados por el compilador, pero se recomienda utilizarlos para facilitar la lectura del código, por ejemplo, las siguientes sentencias también son correctas y generan el mismo resultado que las anteriores, sin embargo la lectura es un poco más complicada:

> **Caso Práctico**
> 
> let a,b,c;a=5;b=10;c=a+b;

Los bloques de código consiste en la declaración de un **conjunto de sentencias** que realizan una tarea específica, para ello se debe utilizar las llaves {}, por ejemplo:

## 1.2. Sintaxis

Tal como sucede en el **lenguaje hablado**, la sintaxis en los lenguajes de programación hace referencia al conjunto de reglas que se aplican para la escritura de las declaraciones. Específicamente en JavaScript la sintaxis para las principales sentencias es manejo de valores; en JavaScript se definen valores fijos y valores variables.

### 1.2.1. Los valores fijos, también llamados literales

Existen dos tipos de **valores fijos o literales**; estos son:

**A) Numéricos**

Que pueden escribirse con punto decimal, por ejemplo, 10.5 o sin punto decimal, 10, por omisión los valores son positivos, en caso de indicar valores negativos se debe escribir el símbolo – antes del valor, por ejemplo, -10.5, -10

**B) Las cadenas**

Que son definidas entre comillas dobles o entre comilla simple, por ejemplo, "Hola mundo", 'Hola mundo'.

### 1.2.2. Los valores variables

Estos son utilizados para almacenar valores fijos que cambian durante la **ejecución del programa**, para lo cual se utilizan las palabras reservadas:

**Let, var y const**

Los **identificadores** en JavaScript son los nombres que se le asignan a las variables, objetos, métodos, propiedades y funciones definidas por el usuario.

> **Importante**
> 
> Para escribir un identificador es **obligatorio** que el primer carácter sea una letra, un guion bajo (_) o un símbolo de peso ($), los siguientes caracteres pueden ser letras, números, guion bajo o símbolo de peso. Los identificadores son sensibles a las mayúsculas, esto es, el identificador miVariable es diferente a mivariable.

## 1.3. Comentarios

Una **buena práctica de programación** consiste en la documentación del código, el objetivo es colocar información que facilite el entendimiento del mismo y permita el mantenimiento futuro o simplemente para que un lector conozca el objetivo del código documentado.

> **Para saber más**
> 
> Para documentar **código** se utilizan los comentarios. En JavaScript los comentarios se pueden colocar en cualquier lugar del código y no afectan la ejecución del mismo ya que el compilador los ignora.

**1. El comentario de una sola línea**

Inicia con dos caracteres de barra diagonal //. A partir de esos caracteres todo el resto de la línea es considerada como comentario por el compilador. Por ejemplo: let a, b, c; //Declaración de las variables a utilizar.

**2. Los comentarios de varias líneas**

Comienzan con una barra diagonal y un asterisco /* y terminan con un asterisco y barra diagonal */. Todo el contenido entre /* … */ es ignorado por el compilador. Por ejemplo:

/* Primera línea del comentario

Segunda línea del comentario */

let a, b, c; //Comentario de una línea

Los **comentarios de múltiples líneas** en ocasiones se utilizan para deshabilitar temporalmente alguna parte del código.

## 1.4. Variables

Una **variable** es un espacio de memoria en donde se puede almacenar un dato de un tipo específico. Los nombres de las variables son identificadores y deben cumplir con lo señalado en la sintaxis del lenguaje. Los identificadores de las variables deben ser únicos en cada bloque de código.

> **Importante**
> 
> Las **palabras reservadas** de JavaScript que se utilizan para declarar una variable son var, let y const: var a = 5, es equivalente a let a = 5.

En las sentencias anteriores se realizaron **2 acciones**, la declaración que consiste en indicarle al lenguaje que vamos a necesitar una variable y el sistema operativo asigna un espacio de memoria para ese identificador, pero esa variable no tiene valor, técnicamente el valor es indefinido. El segundo proceso es colocarle un valor a la variable, lo que se denomina inicialización. Para inicializar una variable se utiliza el símbolo de igual (=).

Los valores numéricos se colocan de manera **directa**, son positivos por omisión, al agregar el carácter – el número es considerado negativo. Los valores tipo cadena se escriben entre comilla simple o comilla doble, por ejemplo, var nombre = 'Juan Pérez', o bien, var nombre = "Juan Pérez".

---

Es posible declarar **varias variables** en una sola línea, por ejemplo, var nombre = "Juan Pérez", auto = "Nissan", precio = 100. Sin embargo, las buenas prácticas de programación sugieren que se utilice una declaración por línea, por lo tanto, lo ideal sería lo siguiente:

var nombre = "Juan Pérez",

auto = "Nissan",

precio = 100

En la **sintaxis** de un identificador se puede utilizar el símbolo $ como parte del mismo, al igual que el símbolo de guion bajo _, Por lo tanto, las siguientes declaraciones son válidas:

var $delAuto = 100, _nombre = "Juan Pérez"

La **declaración de variables** utilizando la instrucción let fue introducida en el estándar de JavaScript del año 2015 e introdujo algunas mejoras técnicas. Su utilización a nivel de declaración e inicialización es similar a var. Una diferencia notable es que la sentencia let no permite re-declarar una variable en el mismo bloque de código:

> **Caso Práctico**
> 
> let x = "Juan Pérez"
> 
> let x = 10 //Marca un error de sintaxis: 'x' ya se encuentra declarada
> 
> Pero si utilizamos var, el error no ocurre:
> 
> var x = "Juan Pérez"
> 
> var x = 10 //El valor de 10 es asignado a x sin marcar error

Existen **otras mejoras técnicas** en la utilización de la sentencia let

La **sentencia const**, también introducida en 2015, permite declarar una variable que no cambia de valor durante la ejecución de la aplicación, por ejemplo, const tamaño = 1

*Diferentes tipos de datos*

Una variable puede contener cualquier **tipo de dato** en un momento específico y cambiar su tipo en el momento que sea. Esto es, una variable puede iniciar con un valor de tipo cadena y posteriormente almacenar un tipo numérico, por ejemplo:

let x ="Juan Pérez"

x = 10

Los **lenguajes** que permiten este tipo de comportamiento se llaman dinámicamente tipados, lo que significa que las variables no están vinculadas rigurosamente a un tipo de dato.

Los **tipos de datos básicos** de JavaScript son los siguientes:

**Número**

Representa valores numéricos enteros o con punto decimal, por ejemplo: let entero = 10, condecimal = 5.5. Dentro de los valores numéricos JavaScript tiene un tipo denominado Infinity que representa el infinito matemático y su valor es mayor que cualquier número. También existe el tipo NaN que representa un error de cálculo que se genera como resultado de una operación matemática incorrecta, por ejemplo: let error = "cadena" / 2; Lo anterior significa que las operaciones matemáticas son seguros, siempre obtendremos un resultado, si existe error, obtendremos NaN.

**BigInt**

Representan números enteros realmente grandes; se genera agregando la letra n al final del número, por ejemplo: let x = 1234567890987654321234556789n

**Cadenas**

Es una secuencia de caracteres que se coloca entre comilla simple o comilla doble. También es posible utilizar las comillas invertidas `` que tienen una funcionalidad en la cadena ya que permiten incluir expresiones que son evaluadas en tiempo de ejecución encerrandolas entre ${}: let str = "Hola"; let str2 = 'Mundo'; let strespecial = `¡${str} ${str2}!`;

**Booleano**

Corresponde al valor de falso (false) o verdadero (true), por ejemplo, let bandera = true;

**Null**

Es el valor nulo que representa nada o vacío. let x = null;

**Undefine**

Valor indefinido. let x; alert(x); //el resultado será undefined

Esta característica es esencial para crear aplicaciones web dinámicas y con buena capacidad de respuesta. Los frameworks y bibliotecas amplían sus posibilidades y rendimiento en distintos entornos.

- Las **declaraciones** en JavaScript consisten en escribir instrucciones que incluyen valores, operadores, expresiones, palabras clave y comentarios. La ejecución es secuencial y puede incluir el punto y coma (;) para separar sentencias, especialmente cuando se escriben varias en una misma línea. La claridad en la escritura facilita la comprensión y el mantenimiento del código.

- Los **bloques de código**, delimitados por llaves {}, agrupan sentencias que realizan tareas específicas. Es recomendable usar espacios y saltos de línea para mejorar la legibilidad. Las palabras reservadas del lenguaje no deben utilizarse como identificadores de variables, funciones u objetos.

- Las **variables** son espacios de memoria que almacenan datos de un tipo específico y se declaran mediante var, let o const. La inicialización asigna un valor a la variable, mientras que los identificadores deben cumplir reglas de sintaxis y ser únicos dentro de un bloque de código. let evita redeclaraciones en un mismo bloque, y const define valores constantes.

- Los **tipos de datos** determinan la clase de valores que puede contener una variable, y JavaScript es dinámicamente tipado, permitiendo cambiar el tipo de dato durante la ejecución. Entre los tipos básicos se encuentran números, BigInt, cadenas, booleanos, null y undefined. Comprender los tipos de datos es fundamental para manipular información correctamente en programas.

## 1.2. Dónde se ubica el JavaScript en las páginas HTML

El JavaScript es un lenguaje interpretado, por lo que su ejecución no requiere un proceso de compilación. Recordemos que un lenguaje compilado primero debe ser convertido a lenguaje máquina para ser ejecutado y un lenguaje interpretado es leído directamente del texto plano y ejecutado de manera directa por el navegador.

> **Importante**
> 
> La ejecución del **lenguaje JavaScript es secuencial**, lo que significa que la **interpretación del código (ejecución) se realiza línea por línea**, una después de la otra. Lo anterior obliga a tener cuidado en el **orden de colocación de cada instrucción dentro del código**. Al ser **JavaScript un lenguaje interpretado**, el **código** que recibe el navegador es completamente en **texto plano**, lo cual hace un código muy **ligero** y de fácil **transmisión** por la red.

Otra característica importante es la ejecución del JavaScript en el lado del cliente, lo que significa que el proceso de interpretación y ejecución del código se realiza en la máquina del usuario y con ello se optimiza el uso de los recursos de la red. Aunque el JavaScript también puede ser ejecutado en el lado del servidor, pero ese tema será abordado en otras unidades.

---

Ahora bien, ¿**cómo podemos incluir JavaScript en una página HTML**?, existen tres maneras diferentes:

**Integrado en la etiqueta HTML.**

Algunas etiquetas cuentan con la propiedad onclick que permite incluir código JavaScript, por ejemplo, `<button type="button" onclick='alert("Hola Mundo")'>¡Saludo!</button>`

**Utilizando la etiqueta `<script></script>` de HTML.**

La etiqueta puede ser colocada en cualquier lugar del document HTML, sin embargo, se sugiere colocarla dentro de la etiqueta `<head><script>alert("Hola Mundo")</script></head>` del HTML.

**En un archivo externo.**

El código JavaScript se escribe en un archivo de texto plano con extensión .js y en la etiqueta `<script src="miArchivo.js"></script>`, la etiqueta `<script>` se sugiere colocar entre la etiqueta `<head>` del HTML.

# Recuerda

- **JavaScript** es un lenguaje clave en el desarrollo web moderno, ya que permite dotar de interactividad y dinamismo a páginas inicialmente estáticas. Su evolución lo ha convertido en una herramienta versátil y ampliamente utilizada. Gracias a su ejecución en el navegador, mejora la experiencia del usuario en tiempo real.

- Se trata de un **lenguaje interpretado y estandarizado** como ECMAScript, lo que garantiza su compatibilidad con la mayoría de los navegadores. Al ejecutarse línea por línea, requiere un orden lógico en las instrucciones. Su naturaleza ligera facilita la transmisión y el rendimiento en la web.

- JavaScript se integra de forma natural con **HTML**, complementando la estructura del contenido con comportamientos dinámicos. Esta combinación permite transformar páginas informativas en aplicaciones interactivas. El lenguaje posibilita operaciones básicas como el uso de variables, cadenas y eventos.

- La **inclusión** de JavaScript en una página HTML puede realizarse de distintas formas, ya sea de manera integrada en etiquetas, mediante la etiqueta `<script>` o a través de archivos externos. El uso de archivos .js favorece la organización y el mantenimiento del código. La correcta ubicación del script influye en la ejecución del contenido.

- Las **salidas y resultados** pueden mostrarse al usuario mediante alertas, manipulación del DOM o la consola del navegador. El DOM actúa como una API fundamental para acceder y modificar elementos HTML. La consola es una herramienta clave durante el desarrollo y la depuración del código.

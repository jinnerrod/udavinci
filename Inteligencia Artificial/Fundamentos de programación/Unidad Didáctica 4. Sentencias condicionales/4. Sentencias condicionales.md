# 1. Sentencias condicionales

Las **sentencias condicionales** son una estructura fundamental en la programación que permite a los desarrolladores controlar el flujo de ejecución del programa en función de condiciones específicas. Estas construcciones lógicas permiten que un programa tome decisiones basadas en la evaluación de expresiones booleanas. En términos simples, las sentencias condicionales permiten que un **bloque de código** se ejecute solo si se cumple una determinada condición, proporcionando una herramienta esencial para la creación de lógica y ramificación en los programas.

![Declaración condicional en programación](https://cdn.educalms.com/JTJCNkFWNVRoR2hQNEcyTHBSR1lJdG1RJTNEJTNE-1766575232.png?Expires=1789288622&Signature=DrybW2yzYrZHak4m6B00xWo84M5W6CdIgRGG7nlJxZCoWAMT0tOSn2P67Moy25NEC83lZk7HeDY3HG72SsNCbx0BZmYaGeByG0Zl3k2r5sBKe6qhUZ0p-mph0kV1w5DQjK5iHnavfE7Y8-7Ov9Zw0JphyQeEtURIttOZ2PdoKak2FStal4ytPK1HUzJKqzrUIA3MiAnYPiPFU98Mb3wH4ocGx5le4~xfQdJ4FZQHmMf5ISV3ruohkbcQ8Hmi8b6E86cke3jm3wd9wKVA8Z3EFeHhlOCu6YmkTplR40p6iBPu5Dtb4hY6DTr22Kk~ETUZhp5rtO5FFpPhMO5TblCOOA__&Key-Pair-Id=K2XVTQ1784SQT0)

*Declaración condicional en programación*

> **Ejemplo**
> 
> Un ejemplo común de una sentencia condicional es el **"if-else"**, donde un bloque de código se ejecuta si una condición es verdadera y otro bloque se ejecuta si la condición es falsa. Esta capacidad para realizar bifurcaciones en el flujo del programa es esencial para adaptar la ejecución del código a diferentes situaciones, mejorando la flexibilidad y la capacidad de respuesta de las aplicaciones. Las sentencias condicionales son fundamentales en la construcción de algoritmos y programas robustos, ya que permiten que el software responda dinámicamente a diferentes escenarios y condiciones durante la ejecución.

Además del "if-else", existen otras **estructuras condicionales** como "switch-case", que facilitan la evaluación de múltiples posibles valores de una variable de manera más organizada y legible. Esta estructura es especialmente útil cuando se deben comparar varias opciones discretas, evitando la repetición excesiva de sentencias "if-else" y mejorando la claridad del código. De esta manera, se optimiza la legibilidad y el mantenimiento de los programas, lo que resulta clave en proyectos de mayor complejidad.

> **Importante**
> 
> Las **sentencias condicionales** no solo permiten ejecutar código según condiciones específicas, sino que también pueden combinarse con operadores lógicos como AND, OR y NOT para crear decisiones más complejas y precisas. Esto posibilita que un programa considere múltiples factores simultáneamente antes de decidir qué bloque de código ejecutar, aumentando la sofisticación de la lógica implementada y la adaptabilidad del software a situaciones reales.
> 
> Otro aspecto importante es que las sentencias condicionales son esenciales para la **validación de datos**. Antes de procesar información, un programa puede verificar si los datos cumplen ciertos criterios y, en caso contrario, ejecutar un manejo de errores o una ruta alternativa. Este control de flujo asegura la integridad de los datos y evita fallos o comportamientos inesperados, contribuyendo a la confiabilidad general del software.

## 1.1. Operadores

De manera general podemos decir que hay diferentes **tipos de operadores** en **JavaScript**; estos son los matemáticos y los de comparación, de igualdad estricta y relacionales; a continuación, presentamos cada uno.

**Los operadores matemáticos**

Estos son:

la suma (+)

resta (-)

multiplicación (*)

división (/)

Su funcionamiento es sencillo ya que seguramente ya los trabajaste en las operaciones de educación básicas de matemáticas. Adicionalmente en JavaScript se tiene el operador módulo o resto:

**El operador módulo o resto (%):** se utiliza para obtener el resto de la división entera de los operandos.

Por ejemplo:

alert(5 % 2); //Muestra 1

También se tiene el operador de exponenciación:

El operador de exponenciación (**) eleva un número a una potencia, por ejemplo:

---

alert(2 ** 3); //Muestra 8. El exponente puede ser un número decimal, por ejemplo: alert(16 ** (1/2)); //Muestra 4

El símbolo de suma (+) tiene un **comportamiento diferente** a la adición cuando uno de los operandos es una **cadena**.

> **Importante**
> 
> En esos casos el + se convierte en operador de concatenación y convierte todos los operandos en cadenas, por ejemplo: alert("2+2=" + 4); //Muestra la cadena 2+2=4
> 
> La ejecución de la expresión se realiza **de izquierda a derecha**, por ejemplo:
> 
> alert(2 + 2 + "=2+2"); //Muestra la cadena 4=2+2. Pero: alert("2+2=" + 2 + 2); //Muestra la cadena 2+2=22.

Como lo has estado viendo en varios códigos el **operador de asignación** es el símbolo de igual (=).

Una característica de este operador es la **asignación encadenada**, por ejemplo: let a = b = c = 5; //Se asigna 5 a las variables a, b, c. En algunas ocasiones necesitamos aplicar un operador a una variable y asignar el nuevo resultado a la misma variable, por ejemplo:

---

> **Ejemplo**
> 
> let n = 2; n = n +1; la anterior **instrucción** se puede cambiar por: n += 1; la ejecución es exactamente igual. La expresión corta aplica para todos los operadores: +=, -=, *=, /=

También existe un operador para el **incremento** (++) o **decremento** (--) en 1 del valor de una variable, por ejemplo: n += 1; se puede cambiar por: n++; para un incremento en uno o n--; para un decremento en uno.

> **Importante**
> 
> El incremento o decremento se puede colocar **antes** (prefijo) o **después** (sufijo) de la variable, por ejemplo: ++n; n++; el orden de colocar antes o después sólo tiene influencia cuando la variable es asignada, ya que ++n primero incrementa el valor y luego regresa ese valor, en cambio, n++ primero regresa el valor y luego lo incremente, tenemos así: let n = 2; alert(n++); //Muestra el número 2 y después incrementa el valor de n a 3. en cambio: alert(++n); muestra 3, porque primero realiza el incremento y luego devuelve el valor

---

**Operadores de comparación**

En **JavaScript** los **operadores de comparación** son:

- mayor que >
- menor que <
- mayor o igual >=
- menor o igual <=
- diferente !=
- igual ==.

Algunos **ejemplos** son: alert(2 > 1); //Verdadero, alert(2 == 1); //Falso, alert(2 != 1); //Verdadero.

Las **cadenas** pueden ser comparadas con los operadores de comparación y para ello en JavaScript se ejecuta el proceso siguiente:

> **Importante**
> 
> 1. Compara el primer carácter de ambas cadenas.
> 
> 2. Si el primer carácter de la primera cadena es mayor (o menor) que el de la otra cadena, entonces la primera cadena es mayor (o menor) que la segunda. Termina el proceso.
> 
> 3. De lo contrario, si los primeros caracteres de ambas cadenas son los mismos, compare los segundos caracteres de la misma manera.
> 
> 4. Repita hasta el final de cada cadena.
> 
> 5. Si ambas cadenas tienen la misma longitud, entonces son iguales. De lo contrario, la cadena más larga es mayor.
> 
> Ejemplos: alert("Z" > "A"); //Verdadero, alert("Dos" > "Doce"); //Verdadero.

---

Es posible comparar una **cadena de dígitos** con un **valor numérico**, en estos casos JavaScript convierte la cadena a número, por ejemplo:

> **Ejemplo**
> 
> alert("2" > 1); //Verdadero, el 2 es convertido en número. El valor falso se convierte en 0 y el verdadero en 1: alert(false == 0); //Verdadero.
> 
> Una **cadena vacía** es convertida a falso y una cadena con al menos un carácter es convertida a verdadero: alert("" == false); //Verdadero, alert("Hola" == true); //Verdadero

Además de los **operadores de comparación**, se encuentran también los llamados:

**Operadores de igualdad estricta**

**Por ejemplo:**

alert(false === 0); //Falso ya que son de diferente tipo.

Ya por último se encuentran los operadores relacionales, los cuales se definen de la siguiente manera.

**Operadores relacionales**

- El **operador && (AND)** genera un verdadero si los dos operandos son verdaderos, si alguno es false el resultado es falso.
- El **operador || (OR)** regresa verdadero si alguno de los operandos es verdadero, sólo regresa falso cuando los dos son falsos.
- El **operador de negación (!)** cambia el valor de verdad del operando que lo sucede.

## 1.2. Sentencia condicional

Es una **sentencia de control** que permite al desarrollador definir la ejecución de un conjunto de instrucciones u otras como resultado de la evaluación de una condición. Una de estas sentencias es la instrucción if, que se utiliza para indicar si se ejecuta un grupo de instrucciones si el resultado de la evaluación de una sentencia condicional es verdadera:

La **sintaxis** de la instrucción if es:

if (sentencia) {

instrucciones;

}

La **sentencia condicional** debe regresar un valor de falso o verdadero. El grupo de instrucciones se ejecuta cuando el resultado es verdadero. En caso de un resultado falso en la sentencia, las instrucciones no se ejecutan.

La **sentencia if** puede incluir la cláusula else en su estructura y tener dos bloques de instrucciones, una que se ejecuta cuando el resultado de la sentencia es verdadero y el otro cuando el resultado es falso.

*Sentencia condicional*

if (sentencia) {

instrucciones1;

}

else {

instrucciones2;

}

La **instrucción** evalúa la sentencia condicional, si el resultado es verdadero se ejecuta el grupo de instrucciones1 en caso contrario se ejecuta el grupo de instrucciones2.

> **Importante**
> 
> En algunos lenguajes, como es el caso de JavaScript, existe un **operador ternario** ? cuyo comportamiento es similar a la sentencia if () else. Es el único operador que tiene tres operandos.

El operador generalmente se utiliza cuando queremos **regresar** un valor u otro dependiendo de una condición. Por ejemplo, queremos saber si la edad de una persona es mayor o igual a 18 años y así regresar a una cadena de "adulto" o "menor de edad". Por supuesto que se puede hacer implementado una sentencia condicional if de la siguiente manera:

> **Ejemplo**
> 
> let edad = 20;
> 
> let letrero;
> 
> if (edad >= 18) {
> 
> letrero = "mayor de edad";
> 
> }
> 
> else {
> 
> letrero = "menor de edad";
> 
> }

---

Sin embargo, es posible generar un código más compacto con el **operador ?** De la siguiente manera:

let edad = 20;

let letrero = (edad >= 18) ? "mayor de edad" : "menor de edad";

La **diferencia en código** es considerable y la ejecución es similar. El operador ? Al igual que el if, evalúa la sentencia condicional y si el resultado es verdadero regresa la primera instrucción, en caso contrario regresa la segunda instrucción.

Las **sentencias condicionales** se pueden anidar. Lo anterior consiste en colocar una sentencia dentro del cuerpo de otra sentencia igual. Por ejemplo: supongamos que necesitamos obtener un letrero de niño, adolecente, adulto, adulto mayor si la edad es <15, <18, <50 respectivamente. >

> 
> }

> }

Como puedes observar tenemos sentencias **if** else anidadas, una se encuentra dentro de la otra. Cuando tenemos sentencias if else anidadas y la primera instrucción del bloque de instrucciones del else corresponde a una sentencia if, es posible modificar el código y escribir la sentencia else if, por ejemplo:

> **Ejemplo**
> 
> if (edad < 15) {
> 
> letrero = "niño";
> 
> }
> 
> else if (edad < 18) {
>

*Presionar tecla "Espacio"*

La **sentencia switch** permite evaluar una variable de tipo numérico entero, carácter o cadena contra varios posibles valores. La sintaxis de la sentencia es:

> **Ejemplo**
> 
> switch(variable) {
> 
> case valor1:
> 
> instrucciones1;
> 
> break;
> 
> case valor2 :
> 
> instrucciones2;
> 
> break;
> 
> …
> 
> [default:
> 
> instruccionesN;
> 
> break;]
> 
> }

La **instrucción** obtiene el **valor de la variable** o **expresión** que va entre paréntesis (), la cual debe generar o ser un valor entero, carácter o cadena. Ese valor es comparado de manera secuencial con cada una de las etiquetas case con el operador de igualdad estricta (===). Si el valor coincide con la constante de una etiqueta case, se ejecutan la o las instrucciones asociadas a esa etiqueta case. La última instrucción de una etiqueta case siempre debe ser break;, la cual finaliza la ejecución de la instrucción switch. De manera opcional se puede utilizar una etiqueta default, que se ejecutará en caso de que el valor no coincida con ninguna de las constantes de las etiquetas case.

Las **sentencias case** son evaluadas con un operador de igualdad estricto. Es obligatorio colocar la sentencia break para finalizar una instrucción case, en caso de no colocar break la ejecución del programa continua línea a línea. Lo anterior permite que se puedan agrupar case si se requiere comparar con varios valores utilizando el **operador || (OR)**.

> **Ejemplo**
> 
> let numero = 5;
> 
> switch (numero) {
> 
> case 0:
> 
> case 1:
> 
> alert("Es un 0 o un 1");
> 
> break;
> 
> case 2:
> 
> alert("Es un 2");
> 
> break;
> 
> case "3":
> 
> alert("Nunca se ejecuta por ser una cadena");
> 
> break;
> 
> case 4:
> 
> alert("Es un 4");
> 
> break;
> 
> case 5:
> 
> alert("Es un 5");
> 
> break;
> 
> default:
> 
> alert("Es más grande de 5");
> 
> break;
> 
> }

# Recuerda

- Las **sentencias condicionales** permiten controlar el flujo de ejecución de un programa evaluando condiciones booleanas. A través de estructuras como if-else, el código se ejecuta de manera selectiva según se cumpla o no la condición establecida, lo que facilita la toma de decisiones dentro del software.

- Los **operadores** son esenciales para construir expresiones condicionales. Los operadores matemáticos realizan cálculos básicos, el operador de asignación modifica valores, los operadores de comparación generan resultados booleanos y los operadores lógicos permiten combinar múltiples condiciones para mayor control del flujo.

- Las **sentencias if** pueden combinarse con else y else if para crear bifurcaciones más complejas, adaptando la ejecución del programa a múltiples escenarios posibles. La anidación de sentencias condicionales permite evaluar condiciones jerárquicas o dependientes entre sí de manera ordenada y eficiente.

- El **operador ternario ? :** ofrece una alternativa compacta a las sentencias if-else, devolviendo un valor u otro según la condición evaluada. Este operador puede anidarse, permitiendo definir múltiples alternativas de manera concisa y manteniendo la legibilidad del código.

- La **sentencia switch** facilita la evaluación de una variable contra múltiples valores posibles. Cada caso (case) se compara mediante igualdad estricta, se ejecuta con break y puede incluir un default opcional, proporcionando una estructura clara y eficiente para manejar condicionales múltiples.

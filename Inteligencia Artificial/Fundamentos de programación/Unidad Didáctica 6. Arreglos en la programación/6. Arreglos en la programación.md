# 1. Arreglos en la programación

Los **arreglos**, también conocidos como **listas o vectores**, son estructuras de datos fundamentales en la programación que permiten almacenar y organizar elementos del mismo tipo bajo un solo identificador. Estos elementos pueden ser números, cadenas de texto u objetos más complejos, y están dispuestos secuencialmente en el arreglo. La capacidad para acceder a los elementos mediante índices facilita la manipulación y gestión eficiente de conjuntos de datos en la programación.

*Arreglo en la programación*

Una de las principales **ventajas** de los arreglos es que permiten realizar operaciones de manera ordenada y predecible. Por ejemplo, se pueden:

- Acceder a un elemento específico mediante su índice.
- Modificar el valor de un elemento existente.
- Recorrer todos los elementos para aplicar operaciones como sumas, búsquedas o transformaciones.

La importancia de los arreglos radica en su **versatilidad** para almacenar información de manera estructurada, lo que facilita operaciones como la búsqueda, clasificación y manipulación de datos en programas. Gracias a su organización lineal, los desarrolladores pueden implementar algoritmos de manera más sencilla y eficiente.

Además, los arreglos son esenciales en la **gestión de conjuntos de información** en diversos contextos de desarrollo de software, desde aplicaciones simples hasta sistemas complejos. Su uso optimiza la memoria y mejora la legibilidad del código al agrupar datos relacionados bajo un mismo identificador.

> **Importante**
> 
> Los arreglos constituyen una herramienta poderosa que contribuye a la **eficiencia**, **organización** y **claridad** en la programación. Dominar su uso permite a los programadores gestionar datos de forma sistemática y aplicar algoritmos de manera efectiva, siendo un pilar fundamental en cualquier lenguaje de programación moderno.

## 1.1. Declaración y creación de arreglos

Los **arreglos** en **JavaScript** son una **colección de elementos** que son **referenciados bajo el mismo nombre**. La sintaxis para crear un objeto tipo arreglo es:

> **Importante**
> 
> let arreglo = new Array(elemento0, elemento1, …, elementoN)
> 
> let arreglo = Array(elemento0, elemento1, …, elementoN)
> 
> let arreglo = [elemento0, elemento1, …, elementoN]

En los ejemplos anteriores se crea una colección de nombre arreglo que contiene como valores iniciales lo colocado como elemento0, elemento1, …, elementoN.

Podemos tener **acceso a cada uno de elementos del arreglo** utilizando un **índice entre corchetes,** el primer elemento se coloca en la posición del índice 0. Por ejemplo:

> **Ejemplo**
> 
> let frutas = ["Naranja", "Manzana", "Plátano"]
> 
> alert(frutas[1]) //Muestra la cadena Manzana que corresponde al segundo elemento en la posición 1

---

Podemos modificar el contenido de un elemento, por **ejemplo**:

**frutas[2] = "Uva"**

Podemos agregar elementos al arreglo:

**frutas[3] = "Pera"**

Es posible conocer el **número de elementos** de un arreglo utilizando la propiedad length:

**alert(frutas.length)**

También es posible mostrar todos los elementos de un arreglo:

**alert(frutas)**

Los **arreglos** pueden tener elementos de cualquier tipo, por ejemplo:

> **Ejemplo**
> 
> let arregloTipos = [ "Cadena", 45, { nombre = "Juan" }, true, function() { alert("hola"); } ]

En el ejemplo anterior, el primer elemento es una cadena, el segundo un tipo numérico, el tercero es un objeto con una propiedad, el cuarto es un booleano y el último es una función. Si escribimos:

> **Ejemplo**
> 
> alert(arregloTipos[0]); //Se muestra Cadena
> 
> alert(arregloTipos[1]); //Se muestra 45
> 
> alert(arregloTipos[2].nombre); //Se muestra Juan
> 
> alert(arregloTipos[3]); //Se muestra verdadero
> 
> arregloTipos[4](); //Se muestra hola

---

Para recorrer los elementos de un arreglo se puede utilizar una sentencia cíclica:

for (let i = 0; i < frutas.length; i++)

alert(frutas[i]);

También es posible utilizar la instrucción for…of:

for (let fruta of frutas)

alert(fruta);

Otra opción para recorrer un elemento es utilizar el método forEach():

frutas.forEach(function(elemento) { alert(elemento) });

Los arreglos pueden utilizarse como una colección tipo pila utilizando los métodos push y pop:

frutas.push("Plátano"); //Agrega un elemento al final del arreglo

frutas.pop(); //Saca el último elemento del arreglo, en el ejemplo se obtiene Plátano

También es posible utilizar un arreglo como una estructura tipo cola con los métodos push y shift:

frutas.shift(); //Saca el primer elemento del arreglo y recorre todos los elementos

También es posible agregar un elemento al inicio del arreglo utilizando el método unshift.

---

Otro **método de los arreglos es el sort()** que ordena los elementos de manera ascendente. Sin embargo, se debe tener cuidado cuando los elementos del arreglo son numéricos, ya que el método sort() convierte el valor del elemento en una cadena. Por lo que es necesario utilizar una función de ayuda para ordenar elementos numéricos de manera correcta, por **ejemplo**:

> **Ejemplo**
> 
> let numeros = [20, 100, 30, 50];
> 
> alert(numeros.sort()); //Genera como salida: 100, 20, 30, 50
> 
> alert(numeros.sort(function(a, b){return a - b})); //Genera como salida: 20, 30, 50, 100

El reverse() reordena los elementos del arreglo de manera **inversa**. El indexOf(elementoaBuscar) busca el elemento llamado elementoaBuscar y regresa su índice. lastIndexOf(elementoaBuscar) igual que indexOf pero inicia del final hacia el inicio.

Es posible convertir a cadena un arreglo utilizando el **método toString()**, que genera una cadena con todos los elementos del arreglo separados por coma, por ejemplo:

> **Ejemplo**
> 
> let frutas = ["Naranja", "Manzana", "Plátano"]
> 
> alert(frutas.toString()); //Genera de salida la cadena: Naranja,Manzana,Plátano

Otra manera de obtener una **cadena** con todos los **elementos del arreglo** es utilizar el método join(), el cual recibe como parámetro una cadena que es utilizada como separador de elemento, por ejemplo:

> **Ejemplo**
> 
> alert(frutas.join(" : ")); //Genera la cadena: Naranja : Manzana : Plátano

## 1.2. Paso de arreglos a los métodos

Los **arreglos** son tratados como cualquier otro **objeto** al momento de pasarlo como parámetro a una función. El pase de arreglos hacia una función es por referencia, lo que significa que cualquier cambio en el arreglo dentro de la función afecta al arreglo original pasado como parámetro. **Por ejemplo**:

> **Ejemplo**
>
> let numeros = [10, 20, 30];
>
> miFuncion(numeros); //muestra los números 10, 20, 30
>
> alert(numeros[0]); //muestra el número 100 que fue modificado dentro de la función
>
> function miFuncion(parametro) {
>
> for (let i = 0; i < parametro.length; i++) {
>
> alert(parametro[i]);
>
> }
>
> parametro[0] = 100;
>
> }

## 1.3. Arreglos multidimensionales

Los **elementos** que integran un **arreglo** pueden ser, a su vez, otros arreglos, lo que permite la creación de estructuras más complejas conocidas como arreglos multidimensionales. Este tipo de arreglos es útil para representar datos organizados en filas y columnas, como matrices o tablas, y facilita la manipulación de información en dos o más dimensiones.

> **Ejemplo**
>
> Por ejemplo, si se quiere crear una **matriz de 3x3**, podemos definirla así:
>
> let matriz = [ [1, 2, 3], [4, 5, 6], [7, 8, 9] ];

En este caso, cada elemento del arreglo principal es a su vez un arreglo que representa una **fila de la matriz**.

Para acceder a los elementos de un arreglo multidimensional, es necesario utilizar múltiples índices que indiquen la posición en cada dimensión. Por **ejemplo**:

alert( matriz[0][0] ) // muestra el primer elemento de la primera fila

De esta forma, matriz[1][2] accedería al tercer elemento de la segunda fila, y así sucesivamente.

Los **arreglos multidimensionales** amplían las capacidades de los arreglos simples, permitiendo modelar datos más complejos, realizar operaciones matemáticas, almacenar información tabular y organizar elementos de manera estructurada en varias dimensiones. Su comprensión es esencial para manejar matrices, tablas y estructuras avanzadas en programación.

## 1.4. Listas de argumentos con longitud variable

Estas listas son métodos capaces de **variar** el número de parámetros; es decir, son de longitud variable. Se utilizan cuando no se conoce de antemano cuántos argumentos se recibirán en una función o método. En la literatura y en la programación, suelen denominarse **"varargs"**, ya que se comportan como un arreglo que puede almacenar múltiples valores pasados a la función. Esto permite escribir código más flexible y reutilizable, adaptándose a distintas situaciones sin necesidad de sobrecargar métodos.

> **Importante**
>
> La **sintaxis de parámetro vararg** depende del lenguaje de programación, pero generalmente se indica con tres puntos (...) antes del nombre del parámetro, por ejemplo: function suma(...numeros). Internamente, los valores recibidos se tratan como un arreglo, lo que permite iterar sobre ellos, aplicar operaciones o pasarlos a otras funciones. Esta característica es especialmente útil en funciones matemáticas, concatenaciones o cualquier método que necesite procesar un número indefinido de argumentos.

La sintaxis de parámetro vararg es como sigue:

**type… nombreObjetoOPrimitivo**

Para generar una vararg en un método, se debe declarar el tipo de dato al que se hace referencia, así como una elipsis (...), y el nombre; por ejemplo:

> **Ejemplo**
>
> public void addFactura(Factura ... variasFacturas ){
>
> for(Factura f:variasFacturas) {
>
> facturas.add(f);
>
> }
>
> }

# Recuerda

- Los **arreglos** son estructuras de datos que permiten almacenar múltiples elementos bajo un mismo identificador. Su acceso mediante índices facilita la manipulación eficiente de datos homogéneos o heterogéneos dentro de un programa.
- La **declaración de arreglos** puede realizarse con [] o new Array(), y sus elementos pueden modificarse, agregarse o eliminarse usando métodos como push, pop, shift y unshift. Esto proporciona flexibilidad para gestionar colecciones de información.
- Los arreglos pueden recorrerse mediante **bucles for, for…of** o el **método forEach()**, permitiendo procesar cada elemento de manera sistemática. Estas técnicas facilitan la iteración sobre datos y la ejecución de operaciones repetitivas.
- Se pueden crear **arreglos multidimensionales** utilizando arreglos dentro de arreglos, lo que permite representar matrices o estructuras complejas. Cada elemento se accede mediante múltiples índices, ampliando la capacidad de modelado de datos.
- Los arreglos pueden pasarse como **parámetros a funciones por referencia**, lo que implica que cualquier modificación dentro de la función afecta al arreglo original. Esto es útil para el manejo de colecciones de datos sin duplicar memoria ni estructuras.

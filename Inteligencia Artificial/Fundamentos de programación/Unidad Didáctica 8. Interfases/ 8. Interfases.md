# Introducción

El estudio de las **interfaces** permite comprender cómo se produce la interacción entre las personas usuarias y las aplicaciones web de forma eficaz y accesible, actuando como un vínculo directo entre el sistema y la experiencia de uso. El diseño adecuado de interfaces contribuye a mejorar la usabilidad y la accesibilidad digital. La correcta gestión de eventos favorece una interacción más fluida. Estos elementos permiten crear aplicaciones más intuitivas. El enfoque se orienta a la experiencia de uso. Todo ello resulta esencial en el desarrollo de entornos web modernos.

# 1. Interfases

En **programación**, las interfaces son estructuras clave que definen un conjunto de métodos y propiedades que deben ser implementados por cualquier clase que las utilice. Estas proporcionan un contrato que especifica la funcionalidad que una clase debe ofrecer, sin detallar cómo se realiza internamente. Las interfaces permiten la creación de códigos más modularizados y flexibles al facilitar la implementación de múltiples clases que cumplen con los mismos requisitos, fomentando así la interoperabilidad y la coherencia en el diseño de software.

> **Importante**
> Las **interfaces** son especialmente útiles en lenguajes de programación orientados a objetos, donde una clase puede implementar múltiples interfaces, permitiendo la adaptabilidad y extensibilidad del código. Al utilizar interfaces, los desarrolladores pueden establecer estándares claros para la comunicación entre componentes del software, promoviendo la consistencia y facilitando la colaboración en proyectos de gran escala. En resumen, las interfaces son herramientas esenciales que contribuyen a la creación de sistemas de software modulares y bien organizados, al tiempo que facilitan la colaboración y la mantenibilidad del código.

Además, las interfaces facilitan la **prueba** y el **mantenimiento del software**, ya que permiten intercambiar implementaciones sin modificar la estructura general del sistema. Esto resulta especialmente valioso en entornos de desarrollo ágil, donde los cambios frecuentes y la evolución rápida del código requieren soluciones flexibles y desacopladas. Al definir contratos claros mediante interfaces, se reduce el riesgo de errores al integrar nuevos componentes o actualizar funcionalidades existentes, asegurando la estabilidad del sistema.

Las interfaces también favorecen la **documentación y comprensión del software**, al proporcionar un marco claro que describe qué funciones deben estar disponibles y cómo deben ser utilizadas. Esto resulta útil tanto para desarrolladores que participan en el proyecto como para nuevas incorporaciones al equipo, permitiendo un aprendizaje más rápido y eficiente. Las interfaces representan un pilar fundamental en la construcción de software robusto, escalable y fácilmente mantenible.

## 1.1. JavaScript HTML DOM

El **modelo de objeto** de documento o DOM, por sus siglas en inglés (Document Object Model), es una de las API más importantes con la que cuenta JavaScript y en general cualquier otro lenguaje o herramienta que requiera tener acceso al documento HTML.

> **Importante**
> El **DOM** facilita el acceso a la estructura del documento HTML con la finalidad de poder modificar su estructura, estilo o contenido desde algún lenguaje de programación o de manera directa desde las herramientas de los navegadores. Con el DOM se cuenta con una representación estructurada del documento HTML en grupos de nodos y objetos que cuentan con propiedades que pueden ser leídas o modificadas desde cualquier lenguaje de programación, por ejemplo, con el lenguaje JavaScript.

El DOM cuenta con una serie de **objetos** que permiten tener acceso a las diferentes secciones y contenidos de las páginas HTML. El JavaScript utiliza el DOM para tener acceso a los objetos específicos del documento HTML y poder ejecutar acciones como la creación de nuevos elementos de la página, la modificación de las propiedades de un elemento de la página, cambiar los estilos de los elementos de una página, eliminar elementos de una página, entre otras acciones, métodos y eventos.

El **acceso al DOM desde JavaScript** es directamente utilizando una de las **API´s** específica del navegador llamada **document.**

> **Importante**
> En la API HTML DOM existen objetos que contienen propiedades y realizan acciones, los cuales pueden ser modificadas o ejecutadas desde cualquier lenguaje de programación como el JavaScript.

Una manera de tener acceso al DOM es utilizando el objeto llamado document, que es la representación completa de la página Web actual del navegador. En el document existen elementos que se relacionan con las etiquetas HTML que integran la página Web. Algunos de los **principales métodos del objeto document** que nos permite tener acceso a elementos del DOM son:

**1. GetElementById id**

Busca un elemento en el documento que tenga la propiedad id igual a lo indicado como parámetro. En caso de no encontrar algún elemento, regresa el valor de null.

**2. GetElementsByName nombre**

Regresa una colección de elementos que contienen en la propiedad name lo especificado como parámetro.

**3. GetElementsByTagName nombre_html**

Regresa una colección de elementos del tipo HTML definido en el nombre_html.

Cuando ya se tiene el elemento disponible, es posible leer o modificar sus propiedades, por ejemplo:

**NodeName**

Es la propiedad de solo lectura que define el nombre del elemento.

**TextContent**

Es la propiedad que define el contenido del texto del elemento, es modificable.

**InnerHTML**

Es la propiedad que define el contenido HTML del elemento, es modificable.

También es posible crear **elementos en la página Web**:

**CreateElement**

(etiqueta) Crea en memoria un elemento HTML del tipo definido en la etiqueta.

**CreateComment**

(comentario) Crea en memoria un elemento tipo comentario de HTML.

**CreateTextNode**

(texto) Crea en memoria un elemento de tipo texto de HTML.

Una vez creados los **elementos en memoria** es necesario agregarlos al DOM por medio de los métodos: appendChild(). Inserta un elemento hijo al final de todos los elementos hijos que existen. A continuación, se muestra un ejemplo:

## 1.2. Modelo de objeto del navegador (BOM, por sus siglas en inglés Browser Object Model)

Otra de las API´s importantes es la relacionada con el **modelo de objeto** del navegador que permite a los lenguajes de programación y particularmente a JavaScript tener interacción con el navegador que actualmente muestra la página Web.

> **Importante**
> Con el **BOM (Browser Object Model)** es posible tener acceso y modificar las propiedades de las ventanas del navegador, por ejemplo, abrir, cerrar o mover una ventana del navegador, cambiar el texto que se muestra en la barra de estado, y otras acciones de manipulación de la ventana que no se relacionan con el contenido de la página Web que se está visualizando. El **BOM es el objeto superior del DOM** que se abordó en la sección anterior. En otras palabras, el **DOM es un objeto del BOM**.

Para tener acceso al BOM una de las **API´s específicas** es la window. En JavaScript no es necesario indicar de manera explícita el nombre del objeto window, por ejemplo, cuando utilizamos el método alert() para mostrar una ventana, la interpretación por el navegador es window.alert(), o cuando se utiliza el método prompt() para leer un valor, el navegador ejecuta window.prompt(). Algunos de los métodos del objeto window son:

**1. Window.innerWidth**

Regresa el ancho de la ventana del navegador en pixeles sin considerar la barra de navegación.

**2. Window.innerHeight**

Regresa el alto de la ventana del navegador en pixeles sin considerar la barra de herramientas ni la barra de navegación.

**3. Window.open()**

Abre una nueva ventana del navegador.

**4. Window.close()**

Cierra la ventana actual del navegador.

**5. Window.opener**

Regresa la ventana padre de la ventana actual.

**6. Window.screen.width**

Contiene información del ancho de la pantalla del usuario.

**7. Window.screen.height**

Contiene información del alto de la pantalla del usuario.

**8. Window.location.href**

Regresa el URL de la página actual.

**9. Window.location.hostname**

Regresa el nombre del host de la página actual.

**10. Window.location.pathname**

Regresa el nombre de la ruta de la página actual.

**11. Window.location.protocol**

Regresa el protocolo Web de la página actual.

**12. Window.history.back()**

Carga la página anterior en la lista del historial de navegación del navegador.

**13. Window.history.forward()**

Carga la página siguiente en la lista del historial de navegación del navegador.

**14. Window.navigator.appName**

Regresa el nombre del navegador. Para los navegadores IE, Chrome, FireFox y Safari el nombre es Netscape.

**15. Window.navigator.platform**

Regresa el nombre del sistema operativo que se utiliza para ejecutar el navegador.

**16. Window.navigator.language**

Regresa el idioma del navegador.

## 1.3. Formularios

Los **formularios** **en la programación Web** son una herramienta poderosa ya que **permiten la recopilación de datos de los usuarios**. Son un elemento de interacción altamente utilizado en las aplicaciones Web y en todos los entornos de programación de aplicaciones.

De manera específica en un ambiente de programación Web existen elementos particulares del lenguaje HTML que permiten la definición de una interfaz de usuario para la captura de datos, por ejemplo, la etiqueta

**&lt;input&gt;**

que se utiliza dentro de una estructura

**&lt;form&gt;**

La etiqueta input es una de las más utilizadas en la definición de los formularios, ya que tiene varias propiedades que facilitan la definición del dato que se recibe.

> **Importante**
> La **propiedad type** de la etiqueta tiene el valor text por omisión lo cual indica que la entrada de datos es de tipo texto, pero también es posible definir tipo numérico (number), fecha (date), fecha y hora (datetime), correo electrónico (email), color (color), clave de acceso (password), entre otros.

---

También existen otras **etiquetas** que se pueden integrar a un formulario.

**(<form>)**

Para realizar la entrada de datos, por ejemplo, áreas de texto.

**(<textarea>)**

Para capturar varias líneas, botones.

**(<button>)**

Para ejecutar acciones al hacer clic sobre ellos, entre otros. Es común que las etiquetas de un formulario requieran validaciones para evitar posibles errores de captura de datos. Es en esta actividad en donde se puede utilizar el lenguaje JavaScript.

Una **aplicación específica** del lenguaje JavaScript es la validación de los datos que son ingresados por los usuarios en un formulario. De manera general en la programación Web, la validación de los datos de un formulario se pueden realizar en el lado del servidor o en el lado del cliente.

Cuando se realiza la validación en el lado del servidor, los **datos** son mandados al servidor y posteriormente evaluados para su validación, lo cual es un proceso válido, sin embargo implica el proceso de envío de datos al servidor, que en algunos entornos puede significar un consumo innecesario de recursos. Con JavaScript la validación se puede realizar directamente en el cliente, evitando con ello la transferencia de datos al servidor y optimizando los recursos de comunicaciones. La validación de datos en el lado del cliente se puede realizar utilizando atributos de validación de las etiquetas HTML o con código de programación en JavaScript.

---

La **validación** con **atributos** se puede realizar colocando:

**Required**

Indica que un campo de formulario de contener datos

**Minlength**

Maxlength define la longitud mínima y máxima de una cadena texto.

**Min, max**

Definen el valor mínimo y máximo de un valor numérico.

**Pattern**

Define una expresión regular que establece un patrón en la entrada de dato.

La validación con atributos se realiza en el **cliente** al momento en que se intenta mandar el formulario al servidor, si todos los atributos son verdaderos, el formulario ejecuta la acción de mandar los datos, en caso contrario los datos no serán enviados.

# Recuerda

- Las **interfaces** en programación definen contratos de métodos y propiedades que las clases deben implementar, facilitando la modularidad y coherencia del software.

- Su uso permite la **adaptabilidad** y **extensibilidad** del código, fomentando la colaboración y estandarización en proyectos de gran escala. El DOM representa la estructura de un documento HTML y puede ser manipulado mediante JavaScript para modificar elementos, estilos y contenido dinámicamente.

- El **BOM** proporciona acceso a propiedades y métodos del navegador, permitiendo gestionar ventanas, historial, pantalla y ubicación sin afectar el contenido de la página.

- Los **formularios HTML** permiten la captura de datos del usuario y pueden ser validados tanto del lado del cliente como del servidor, optimizando la seguridad y eficiencia de la aplicación.

- La **combinación** de interfaces, DOM, BOM y formularios contribuye a construir aplicaciones web modulares, interactivas y fácilmente mantenibles, con estandarización y control de datos.

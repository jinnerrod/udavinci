# Introducción

**jQuery** es un framework de JavaScript diseñado para simplificar la manipulación del DOM, la gestión de eventos y la realización de animaciones en páginas web. Facilita la interacción con elementos HTML mediante una sintaxis más concisa y fácil de usar que la de JavaScript puro. Permite realizar llamadas **AJAX** de manera sencilla, mejorando la comunicación con servidores y la actualización dinámica de contenido. Su compatibilidad con múltiples navegadores reduce los problemas de inconsistencias y errores en distintos entornos.

Con jQuery, los **desarrolladores** pueden crear interfaces interactivas de manera más rápida y eficiente. Proporciona métodos integrados para recorrer, filtrar y modificar elementos del **DOM** sin necesidad de código complejo. Su ecosistema incluye plugins que amplían la funcionalidad, promoviendo la reutilización de soluciones ya existentes. Aprender jQuery mejora la capacidad de trabajar en proyectos colaborativos y equipos diversos. Este framework sigue siendo relevante para mantener proyectos legados y comprender la evolución de librerías modernas como React o Vue. Dominar jQuery permite optimizar la experiencia de usuario y el rendimiento de aplicaciones web de forma accesible y estructurada.

# 1. Framework Jquery

**jQuery**, un framework de JavaScript, ha sido una herramienta clave en el desarrollo web desde su introducción. Diseñado para simplificar tareas comunes en la manipulación del DOM (Modelo de Objetos del Documento) y el manejo de eventos, jQuery ha allanado el camino para una escritura de código más concisa y eficiente en aplicaciones web. Su popularidad radica en su capacidad para simplificar la interacción con HTML, gestionar animaciones, realizar solicitudes AJAX y mejorar la accesibilidad de las páginas web, todo ello con una **sintaxis clara y fácil de entender**.

jQuery ha sido particularmente valioso para los **desarrolladores web** al ofrecer una capa de abstracción sobre las complejidades de JavaScript, permitiendo un desarrollo más rápido y consistente en diversos navegadores. Aunque el ecosistema web ha evolucionado con el tiempo y se han introducido nuevas tecnologías, jQuery sigue siendo utilizado en muchos proyectos y proporciona una solución robusta y accesible para aquellos que buscan mejorar la interactividad y la funcionalidad de sus sitios web.

Además, jQuery facilita la **compatibilidad** entre navegadores, algo que en JavaScript puro puede requerir verificaciones y adaptaciones adicionales. Su extenso catálogo de plugins permite ampliar la funcionalidad de manera sencilla, desde sliders y galerías de imágenes hasta formularios interactivos y efectos visuales avanzados, reduciendo significativamente el tiempo de desarrollo.

> **Ejemplo**
> Por ejemplo, con jQuery, se puede ocultar o mostrar un **elemento** con una sola línea de código: $("#miElemento").toggle();. Esta simplicidad demuestra cómo jQuery agiliza tareas comunes que, de otro modo, requerirían varias líneas de JavaScript puro. Así, jQuery sigue siendo una opción útil para proyectos que buscan rapidez, facilidad de mantenimiento y compatibilidad entre navegadores.

## 1.1. Introducción

Hacer uso de **jQuery** para el desarrollo de aplicaciones web te permite:

1. ahorrar tiempo
2. simplificar tu código

De la misma manera hacer uso de una **librería estandarizada**, te ofrece una manera consistente para implementar las aplicaciones web. Con jQuery podemos realizar las siguientes **operaciones**:

- acceder directamente a los elementos de una página web.

- manipular el DOM.
- manipular el estilo de la página web (CSS).
- crear e interactuar con los eventos de la página.
- definir y crear efectos especiales.
- realizar AJAX.
- interactuar con el browser.
- crear e interactuar con collections y otras estructuras.
- añadir e interactuar con widgets de interfaz de usuario.

## 1.2. Agregando jQuery

Para usar **Jquery** no es necesario instalarlo. Tan solo es necesario contar con una copia del código fuente. Tenemos varias posibilidades:

1. Descargarlo desde su página web y ponerlo en nuestro directorio de trabajo
2. Agregarlo haciendo uso de una CDN (Content Delivery Networks)
3. Agregarlo haciendo uso de algún manejador, por ejemplo, npm, yarn, bower.

Como hemos mencionado, jquery es un **código JavaScript** que vamos a incorporar a nuestros desarrollos. Una vez que elegimos como trabajar con jQuery la pregunta es ¿en qué momento cargamos jQuery?. Existen tres respuestas a esta pregunta.

1. Dentro de las marcas head
2. Al abrir la marca body
3. Al cerrar la marca body

De éstas la última es la mejor opción, pues en este momento **otras librerías**, si es el caso, ya han sido agregadas, pero sobre todo, la página principal ya ha sido cargada. Esto se puede apreciar en el siguiente ejemplo.
